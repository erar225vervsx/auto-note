# 生成AIの回答を仕事で使う前に。誤りを防ぐ確認5ステップ

「ChatGPTに下書きを頼んだら速かった。でも、この内容をそのまま上司や取引先に出して大丈夫だろうか」

生成AIを仕事で使い始めた人の多くが、一度はこう感じたことがあるのではないでしょうか。

この不安は個人だけのものではありません。帝国データバンクが2026年3月に全国の企業を対象に行った「生成AIに関する企業の動向調査」(有効回答1万312社)では、生成AIを業務で活用している企業は34.5%でした。一方で、懸念・課題として最も多く挙がったのは「情報の正確性」で、50.4%にのぼっています。企業の声として「上長の確認と検証に手間がかかるようになった」というコメントも紹介されています。

つまり、多くの職場で「AIで速くなった分、確認が新しい負担になっている」状態が起きています。

この記事では、生成AIの回答を仕事で使う前に、どこを・どの順番で・どこまで確認すればよいかを、手順とコピペで使える指示文(プロンプト)つきでまとめます。読み終えるころには、毎回なんとなく不安なまま読み返すのではなく、決まった手順で短時間に確認できるようになるはずです。

## なぜ生成AIの回答は間違えるのか

### 「もっともらしさ」で文章を作っている

総務省・経済産業省の「AI事業者ガイドライン」の付属資料では、生成AIが事実と異なることをもっともらしく回答する現象を「ハルシネーション」と呼び、生成AIが生み出す誤情報をうのみにすることがリスクになりうると整理しています。

生成AIは、質問に対して「自然で、それらしい文章」を組み立てるのが得意です。ところが、自然な文章であることと、中身が正しいことは別の話です。むしろ文章が整っているほど、読み手は誤りに気づきにくくなります。

### 間違えやすいポイントには傾向がある

実際に使っていると、誤りが入りやすい場所にはおおよその傾向があります。

- 数字(金額、件数、割合、日付、期限)
- 固有名詞(人名、会社名、製品名、法律や制度の名前)
- 出典(「〇〇の調査によると」という記述、URL、書籍名)
- 最新の情報(料金、仕様、制度の改正など、変わりやすいもの)
- 引用(「〇〇氏はこう述べた」といった発言)

逆に、文章の言い回しを整える、箇条書きを文章にする、構成案を出すといった「表現」の作業では、事実の誤りが入り込む余地は比較的小さくなります。

ここが確認作業を軽くするための最大のヒントです。**全部を同じ熱量で疑うのではなく、誤りが入りやすい場所に絞って確かめる**のです。

## まず決める:その出力は「どのくらい確認が必要か」

確認の手間は、出力の使い道によって変えてかまいません。おすすめは、使う前に次の3段階のどれに当たるかを決めることです。

### レベル1:自分だけが使うもの(軽い確認)

- 自分用のメモの整理
- アイデア出し、ブレインストーミング
- 文章の言い換え候補

最終的に自分が判断する材料にすぎないので、ざっと読んで違和感がないかを見る程度で十分です。

### レベル2:社内で共有するもの(要所を確認)

- 会議の議事録や要約
- 社内向けの報告書、チャットでの共有文
- 調べ物のまとめ

数字・日付・担当者名・決定事項など、後で人が行動の根拠にする部分を確認します。

### レベル3:社外に出すもの・判断の根拠になるもの(必ず裏取り)

- 取引先へのメール、提案書、見積もりに関わる文章
- 公開する記事、プレスリリース、SNS投稿
- 契約・法令・お金・健康などに関わる内容

ここは、元の資料や公式情報で一つずつ裏取りします。特に法律・税・医療・投資などに関わる内容は、生成AIの回答を結論として扱わず、公式情報や専門家の確認を前提にしてください。

この仕分けをするだけで、「全部を念入りに確認して疲れる」か「面倒になって何も確認しない」かの両極端を避けやすくなります。

## 誤りを防ぐ確認5ステップ

ここからは、レベル2・3の出力を確認するときの具体的な手順です。

### ステップ1:「事実」と「表現」を分ける

最初に、出力を読みながら「事実を述べている文」と「表現・意見・提案の文」を分けます。

たとえば次のような文があったとします。

> 来月から料金プランが改定されるため、早めの見直しをおすすめします。

この文のうち「来月から料金プランが改定される」は事実の主張で、確認が必要です。「早めの見直しをおすすめします」は提案なので、事実確認の対象ではありません(妥当かどうかは自分で判断します)。

確認の対象を「事実の主張」に絞るだけで、読み返す量はかなり減ります。

### ステップ2:危ない箇所に印をつける

事実の文の中から、先ほど挙げた「誤りが入りやすい要素」に印をつけます。

- 数字・日付・期限
- 固有名詞
- 出典・URL・引用
- 変わりやすい情報(料金、仕様、制度)

紙に印刷しているならマーカー、画面上ならコメント機能や太字で構いません。この作業は後で紹介するプロンプトでAI自身にリストアップさせることもできます。

### ステップ3:元の資料・公式情報と照らし合わせる

印をつけた箇所を、一つずつ「元になる情報」と照らし合わせます。

- 議事録や要約なら:元の録音、文字起こし、会議メモ
- 社内資料のまとめなら:元の資料そのもの
- 製品やサービスの情報なら:提供元の公式サイトや公式ヘルプ
- 法令や制度なら:官公庁の公式ページや法令の原文
- 調査データなら:調査を行った機関の発表資料

ポイントは、**別のAIや、出典がはっきりしないまとめ記事を確認先にしない**ことです。同じ誤りが広まっている可能性があるからです。

また、AIが示した出典URLや資料名は、実際に開いて存在するか、本当にその内容が書かれているかを確認してください。URLがもっともらしくても、ページが存在しなかったり、別の内容だったりすることがあります。

### ステップ4:AIに「自己点検」させる(ただし保証にはしない)

確認作業の一部はAIに手伝わせることができます。たとえば、出力のうち確認が必要な箇所をリスト化させたり、自信がない部分を正直に挙げさせたりする使い方です。

ただし、AIの自己点検は「確認すべき場所を見つける」ための補助であって、「正しいことの保証」にはなりません。AIが「確認しました、正しいです」と答えても、それ自体を根拠にしないでください。最終的な裏取りは、ステップ3の元情報で行います。

### ステップ5:最後は人が判断し、確認した内容を残す

確認が終わったら、次の3つを自分で判断します。

- 確認できなかった事実は、削るか、「未確認」と明記するか
- 表現が強すぎる部分(「必ず」「絶対」「業界No.1」など)は弱めるか
- この内容に自分の名前で責任を持てるか

レベル3の出力では、何を確認したかを簡単に残しておくと安心です。たとえば「金額:見積書の原本と照合済み」「日付:公式発表と照合済み」のように一行ずつメモするだけで、後から聞かれたときに説明できます。

## コピペで使える確認用プロンプト

ここでは、確認作業を楽にするための指示文を3つ紹介します。【 】の部分は自分の状況に合わせて書き換えてください。

### プロンプト1:確認すべき箇所をリスト化する

```
次の文章から、事実確認が必要な箇所をすべて抜き出してください。
対象は、数字・日付・固有名詞・出典・引用・料金や仕様など変わりやすい情報です。
各項目について「該当箇所」「確認すべき内容」「確認先として適切な情報源の種類」を表にしてください。
文章の書き直しはしないでください。

【確認したい文章を貼り付け】
```

「確認先として適切な情報源の種類」を聞いておくと、どこで裏取りすればよいかの見当がつきます。

### プロンプト2:不確かな部分を自分で申告させる

```
あなたが先ほど出した回答について、
1. 確実性が高いと考える部分
2. 推測や一般論にもとづく部分
3. 最新情報でないかもしれない部分
に分けて示してください。
判断できない場合は、正直に「判断できない」と書いてください。
```

これはステップ4の自己点検にあたります。返ってきた答えを鵜呑みにせず、2と3に挙がった部分を優先して確認する使い方がおすすめです。

### プロンプト3:元資料と要約を突き合わせる

```
以下の【元の資料】と【要約】を比べて、
・要約にあって元の資料にない情報
・数字、日付、人名、決定事項の食い違い
・元の資料の重要な点で要約から抜けているもの
を箇条書きで挙げてください。食い違いがない場合は「なし」と書いてください。

【元の資料】
(貼り付け)

【要約】
(貼り付け)
```

議事録やレポートの要約を確認するときに役立ちます。AIが見落とす可能性もあるため、数字や決定事項は自分の目でも確認してください。

なお、社外秘の資料や個人情報を貼り付けてよいかは、勤務先の利用ルールによって異なります。プロンプトを使う前に、社内のガイドラインや利用してよいツールを確認しておきましょう。

## 場面別:どこを重点的に確認するか

### 会議の議事録・要約

議事録は、後から誰かが行動の根拠にする文書です。特に次の項目を元の記録と照合します。

- 決定事項(「検討する」が「決定した」に変わっていないか)
- 担当者名と期限
- 数字(予算、件数、日付)
- 発言者の取り違え

AIの要約は、話の流れを自然にまとめる過程で「まだ決まっていないこと」を決まったかのように書いてしまうことがあります。決定事項の表現は特に注意して読みましょう。

### 取引先へのメール・提案書

社外に出る文章はレベル3です。

- 日付・曜日の組み合わせ(カレンダーで確認)
- 金額・数量・型番(見積書や社内資料と照合)
- 相手の会社名・部署名・名前の表記
- 自社のサービス内容や条件(公式の資料と照合)

加えて、敬語や言い回しが相手との関係に合っているかも確認します。AIの文章は丁寧すぎたり、逆に定型的すぎたりすることがあるため、最後に自分の言葉で一文足すだけでも印象が変わります。

### 調べ物のまとめ

調べ物にAIを使った場合は、出典の確認が中心になります。

- 示された出典が実在するか(実際に開いて確認)
- 出典にその内容が本当に書かれているか
- 情報がいつ時点のものか
- 一次情報(調査機関や公式の発表)にさかのぼれるか

出典が示されない回答は「調べ始めるためのヒント」として扱い、そのまま資料に載せないのが安全です。

## チームで確認を習慣にするコツ

### 確認レベルをチームで共有する

先ほどの3段階を、チーム内で言葉として共有しておくと便利です。「この資料はレベル3なので、数字は原本照合までお願いします」のように伝えるだけで、確認の範囲がはっきりします。

### チェックリストを1枚にまとめる

この記事の5ステップを、次のような短いチェックリストにして共有しておく方法もあります。

- □ 事実の文と表現の文を分けた
- □ 数字・日付・固有名詞・出典に印をつけた
- □ 印をつけた箇所を元資料・公式情報で確認した
- □ 確認できなかった部分を削除または明記した
- □ 自分の名前で出せる内容になっている

毎回この5項目を見るだけで、確認漏れはかなり防ぎやすくなります。

### 「AIを使ったかどうか」より「何を確認したか」を話す

生成AIを使ったこと自体を責めたり隠したりするより、「どこを、何で確認したか」を共有する文化のほうが、品質は安定します。確認の記録が残っていれば、上司や同僚が同じ箇所を二重に確認する手間も減らせます。

## まとめ

生成AIは仕事を速くしてくれる一方で、事実と異なる内容をもっともらしく書いてしまうことがあります。だからこそ、「全部を疑う」のではなく「誤りが入りやすい場所を、決まった手順で確かめる」ことが大切です。

- 出力の使い道で確認レベルを3段階に分ける
- 事実と表現を分け、数字・固有名詞・出典に印をつける
- 元の資料や公式情報で裏取りする(別のAIを確認先にしない)
- AIの自己点検は確認箇所を見つける補助として使う
- 最後は人が判断し、確認した内容を残す

まずは次に生成AIで作った文章を使うとき、「これはレベルいくつか」を決めるところから始めてみてください。それだけでも、確認にかける時間と安心感のバランスが変わるはずです。
