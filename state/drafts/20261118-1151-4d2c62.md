# 生成AIで議事録を作る手順 抜けと誤りを防ぐ確認のコツ

会議のあと、録音や文字起こしを生成AIに渡して議事録を作る。いまや多くの職場で見かける使い方です。総務省の情報通信白書(令和8年版)でも、日本の業務での生成AI利用は議事録やメールの作成補助が最も多いと整理されています。

一方で、こんな不安を感じていませんか。

- AIがまとめた議事録を、そのまま配って大丈夫なのか
- 「決まったこと」と「話に出ただけのこと」が混ざっていないか
- 確認しようにも、どこを見ればいいのか分からない

この記事では、生成AIで議事録を作るときの流れを「会議の前」「AIに渡すとき」「できあがった後」の3段階に分けて、確認するべき箇所と手順を具体的に説明します。特定のツールに依存しない、どの生成AIでも使える考え方です。

## まず知っておきたい、AI議事録で起きやすい誤り

手順の前に、どんな誤りが起きやすいかを押さえておきます。どこを疑えばいいかが分かると、確認の時間をぐっと絞れます。

### 1. 「案」が「決定事項」になる

生成AIは、もっともらしい文章を作るのが得意です。その分、会議で候補として挙がっただけの案が、決定事項として書かれてしまうことがあります。発言されていない期限がToDoに書き込まれる、といった例も紹介されています。

### 2. 数字・日付がずれる

金額、数量、日付は、文字起こしの段階でも要約の段階でも誤りが入りやすい箇所です。「15日」が「50日」に、「3割」が「3万」に、といった聞き間違いは、読み手が気づきにくいのが厄介なところです。

### 3. 固有名詞が別の言葉になる

取引先名、製品名、社内の略語、人名は、音声認識が苦手とする代表例です。一般的な言葉に置き換わったまま要約されると、議事録全体が信用されなくなります。

### 4. 発言者を取り違える

誰が言ったかを取り違えると、「言った・言わない」のトラブルにつながります。マイク1台で全員の声を拾う場合や、参加者が多い会議では特に注意が必要です。

### 5. 録音の質がそのまま精度に出る

雑音の多い場所や、マイクから遠い小さな声は、認識の誤りを増やします。元の文字起こしが乱れていると、AIは文脈を読み違え、要約も不正確になります。

この5つを頭に入れたうえで、具体的な手順に進みましょう。

## 会議の前にやっておくこと

### 録音することを参加者に伝え、了承を得る

会議を録音・文字起こしする場合は、事前に参加者へ伝えて了承を得ておきます。社外の人が参加する打ち合わせでは、特に丁寧に確認しましょう。会議ツールの録音通知だけに頼らず、AIツール側でも同意の扱いがどうなっているかを確かめておくと安心です。

具体的な扱いは、勤務先のルールや契約によって変わります。迷ったときは、社内の担当部署に確認してください。

### 会議の情報を、AIに入力してよいか確認する

会議には、機密情報や個人情報が含まれることが少なくありません。使おうとしている生成AIが、会社として利用を認めたものかどうかを確認します。

確認したいのは、次のような点です。

- 会社が契約・許可したサービスか(個人契約のアカウントを仕事に流用していないか)
- 入力した内容が、AIの学習に使われない設定・契約になっているか
- 社外秘や個人情報を入力してよいと、社内ルールで決まっているか

社内にルールがない場合は、議事録に限らず、まず簡単な利用ルールを決めるところから始めるのがおすすめです。

### 録音環境を整える

精度を上げるいちばん手軽な方法は、録音の質を上げることです。

- マイクを話し手の近くに置く(大きな会議室では複数台を検討する)
- オンライン会議では、各自が自分のPCのマイクで参加する
- 発言するときは名前を名乗ってもらう(「営業の田中です」など)
- 雑音の多い場所を避ける

最後の「名乗ってもらう」は、発言者の取り違えを防ぐのにも役立ちます。

### 固有名詞リストを用意する

会議によく出る取引先名・製品名・社内略語・参加者の氏名を、メモに書き出しておきます。ツールに辞書登録の機能があれば登録し、なければAIに渡すときに一緒に貼り付けます。一度作っておけば、定例会議では使い回せます。

## AIに渡すときのコツ

### 指示で「推測しない」ことを明確にする

議事録作りでいちばん避けたいのは、AIが話されていないことを補ってしまうことです。指示文に、推測を禁じる一文と、決定事項の判定基準を入れておきます。

例として、次のような指示文が使えます。

```
以下は会議の文字起こしです。これをもとに議事録を作成してください。

【ルール】
・文字起こしに書かれていない情報は推測で補わないこと。
・不明な点や聞き取れない箇所は「要確認」と書くこと。
・「決定事項」には、会議の中で合意または承認された内容だけを書くこと。
  候補や意見として出ただけのものは「検討中の事項」に分けること。
・ToDoは「誰が・いつまでに・何を」の形で書き、
  担当者や期限が話されていない場合は「担当未定」「期限未定」と書くこと。
・数字・日付・固有名詞は、文字起こしの表記をそのまま使うこと。

【固有名詞リスト】
(取引先名・製品名・参加者名などを貼り付け)

【出力の形式】
1. 会議名・日時・参加者
2. 決定事項
3. 検討中の事項
4. ToDo(担当・期限・内容)
5. 要確認の箇所
```

ポイントは、「決定事項」と「検討中の事項」を分ける欄を最初から用意することです。分ける場所があるだけで、案と決定が混ざりにくくなります。

### 要確認の欄を必ず作らせる

「要確認の箇所」という欄を設けておくと、AIが自信のない部分を書き出してくれるので、確認の手がかりになります。ただし、ここに出てこない誤りもあります。この欄が空だからといって、確認を省略しないようにしましょう。

### 長い会議は区切って渡す

数時間の会議では、文字起こしが非常に長くなります。一度に渡すと、重要な発言が埋もれやすくなります。議題ごと、または30分〜1時間ごとに区切って要約させ、最後にまとめる方法も試してみてください。

## できあがった議事録の確認手順

AIの出力は「下書き」として扱い、人が確認してから配ります。全文を読み直す必要はありません。誤りが実害につながりやすい箇所に絞って、文字起こしと突き合わせます。

### ステップ1:決定事項を一つずつ確かめる

決定事項に書かれた項目ごとに、文字起こしで該当する発言を探します。確かめるのは次の2点です。

- 本当に「決まった」のか(「〜でいきましょう」「承認します」などの発言があるか)
- 決めたのは誰か(決める権限のある人が合意しているか)

「〜も考えられますね」「検討しましょう」程度の発言なら、検討中の事項に移します。

### ステップ2:ToDoの担当者と期限を確かめる

ToDoは、議事録の中でいちばん後の行動に影響します。担当者の名前と期限が、実際に会議で話されたものかを確認します。「担当未定」「期限未定」になっている項目は、会議の主催者に確認して埋めるか、未定のまま共有して次回決めます。

### ステップ3:数字・日付・固有名詞を拾い読みする

議事録の中の数字、日付、固有名詞だけを目で拾い、文字起こしと照らし合わせます。特に金額と納期は、桁や単位まで確認しましょう。文字起こし自体が誤っている可能性もあるため、怪しいものは録音を聞き直すか、発言した本人に確認します。

### ステップ4:発言者の名前を確かめる

「〇〇さんが提案」「〇〇さんが反対」など、名前と発言が結びついている箇所を確認します。特に、責任や約束に関わる発言は優先して見ます。

### ステップ5:配る前に関係者に一言そえる

確認が済んだら、議事録を共有します。そのとき「AIで作成し、決定事項とToDoは確認済みです。誤りがあればご指摘ください」と一言そえておくと、読み手も気づいた点を伝えやすくなります。

## 確認の負担を減らす運用の工夫

### 確認する人と範囲を決めておく

「誰かが見るだろう」と思っていると、結局だれも確認しないまま配られてしまいます。会議ごとに確認担当を決め、上の5ステップのどこまでを見るかを決めておきます。

### 社内の定例会議から始める

最初から社外の商談で使うより、社内の定例会議で試して、誤りの傾向をつかむほうが安全です。どんな言葉を聞き間違えやすいか、どの欄で誤りが出やすいかが分かってきたら、固有名詞リストや指示文を直していきます。

### 誤りをメモして指示文を育てる

確認中に見つけた誤りは、簡単にメモしておきましょう。

- 聞き間違えた固有名詞 → 固有名詞リストに追加
- 案が決定事項に入った → 判定基準の書き方を具体的にする
- 期限が勝手に入った → 「期限未定」のルールを強調する

こうして少しずつ指示文を直すと、同じ種類の誤りが減っていきます。

## AIに任せないほうがよい場面

最後に、AI議事録の扱いに特に注意したい場面にふれておきます。

- 契約条件や金額の合意など、後で証拠として扱われる可能性がある会議
- 人事評価や個人の事情に関わる話し合い
- 社外秘の情報が多く、入力が社内ルールで認められていない会議

こうした会議では、AIを使うかどうか自体を、事前に関係者や社内ルールと照らして判断しましょう。使う場合でも、確認の範囲を広げ、最終的な記録は人が責任を持って確定させることが大切です。

## まとめ

生成AIで議事録を作るときは、次の流れを意識すると、抜けと誤りを大きく減らせます。

- 会議の前:録音の了承、入力してよいかの確認、録音環境と固有名詞リストの準備
- AIに渡すとき:推測を禁じ、「決定事項」と「検討中の事項」を分け、「要確認」の欄を作らせる
- できあがった後:決定事項、ToDo、数字・日付・固有名詞、発言者の4つを文字起こしと突き合わせる

AIは議事録づくりの手間を減らしてくれますが、「何が決まったか」を確定させるのは人の役割です。まずは次の定例会議で、上の指示文と確認手順を試してみてください。
