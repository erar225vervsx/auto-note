# 生成AIに任せる仕事・任せない仕事 迷わない3つの質問

「この仕事、生成AIに頼んでいいのかな」と迷って、結局手が止まってしまうことはありませんか。

便利そうなのは分かっていても、間違いが出たら困る、社外の情報を入れて大丈夫か分からない、どこまで任せていいか基準がない。こうした迷いは珍しいものではありません。帝国データバンクの2026年の調査でも、生成AIを活用する企業の課題として「情報の正確性」が最も多く、「活用すべき業務の範囲」も上位に挙がっています。

この記事では、仕事を生成AIに任せるかどうかを、毎回その場の気分で決めずに済むように「3つの質問」で判断する方法を紹介します。最後に、よくある業務を実際に当てはめた例と、職場で使える判断メモの形もまとめました。

## 迷う原因は「任せる範囲」が決まっていないこと

生成AIの使い方で迷うとき、多くは「使うか・使わないか」の二択で考えています。けれど実際の仕事は、もっと細かく分けられます。

たとえば「取引先へのお詫びメール」なら、次のように分解できます。

- 状況を整理する
- 文面のたたき台を作る
- 謝罪の内容や補償の範囲を決める
- 最終的に送信する

このうち、たたき台づくりはAIに任せやすく、謝罪の範囲を決めるのは人の仕事です。つまり判断するのは「業務まるごと」ではなく「業務のどの工程か」です。

この前提に立つと、迷いはかなり減ります。「この業務は全部ダメ」と決めつけずに、任せられる工程だけを切り出せばよいからです。

## 判断の3つの質問

工程ごとに、次の3つを順番に確認します。1つでも引っかかれば、その工程はAIに任せないか、条件をつけて任せます。

### 質問1 入力してよい情報だけで作業できるか

最初に確認するのは、作業に必要な情報をAIに入力してよいかどうかです。

個人情報保護委員会は2023年6月に、生成AIサービスの利用について注意喚起を出しています。その中で事業者に対しては、個人情報を含むプロンプトを入力する場合は利用目的の範囲内か十分に確認すること、個人データを入力するなら、その情報が機械学習に使われないことなどをサービス側で十分に確認することを求めています。一般の利用者に向けても、利用規約やプライバシーポリシーを確認したうえで、入力する情報を判断するよう呼びかけています。

実務では、次のように考えると判断しやすくなります。

- 公開済みの情報や、自分で書いた一般的な文章 → 入力しやすい
- 社内の資料や取引先の名前 → 職場のルールと、使っているサービスの設定を確認してから
- 顧客の個人情報、未公開の数字、契約の中身 → 原則として入力しない。必要なら名前や数字を仮のものに置き換える

職場に利用ルールがある場合は、そちらが優先です。ルールがない場合は、自分だけで判断せず、上司や担当者に一度確認しておくと安心です。

### 質問2 出てきた答えの正しさを、自分で確かめられるか

生成AIの回答には誤りが含まれることがあります。個人情報保護委員会の注意喚起でも、応答結果は確率的な相関関係に基づいて生成されるため、不正確な内容が含まれることがあると説明されています。

そこで大事なのは、「AIが正しいか」ではなく「自分が確かめられるか」で判断することです。

- 確かめやすい: 自分が出席した会議の議事録、自分が内容を知っているメールの下書き、手元にある資料の要約
- 確かめにくい: 自分が詳しくない分野の説明、出典の分からない数字、最新の制度や料金

確かめにくい工程を任せる場合は、「元になる資料を渡し、資料に書いていないことは書かないよう指示する」「出てきた事実は一次情報で確認する」という条件をつけます。確認する時間がとれないなら、その工程は任せないほうが安全です。

### 質問3 間違えたとき、取り返しがつくか

最後に、もし誤りが残ったまま進んでしまったら、どの程度の影響があるかを考えます。

- 取り返しがつく: 社内向けのメモ、自分用の下調べ、出す前に必ず人が読む下書き
- 取り返しがつきにくい: 社外にそのまま出る文書、お金や契約に関わる判断、人の評価や採否に関わる判断

取り返しがつきにくい工程ほど、AIに任せるのは「材料の整理」までにとどめ、決める部分は人が持つようにします。最終判断と責任は人に残す、という線引きです。

## 判断結果は3段階で考える

3つの質問の結果は、次の3段階にまとめると職場で共有しやすくなります。

### 任せてよい

3つの質問すべてに問題がない工程です。入力しても問題のない情報だけで作業でき、結果を自分で確かめられ、間違えても影響が小さいもの。

例: 文章の言い回しの調整、アイデア出し、自分が作った資料の要約、社内メモの体裁を整える作業

### 条件つきで任せる

どこか1つに不安があるものの、条件をつければ使える工程です。

- 情報に不安がある → 名前や数字を仮のものに置き換える
- 正しさに不安がある → 元資料を渡し、事実は一次情報で確認する
- 影響に不安がある → たたき台までにして、人が必ず手を入れる

例: 取引先へのメールの下書き、議事録の作成、社外向け資料の構成案

### 任せない

条件をつけても不安が残る工程です。

例: 顧客の個人情報をそのまま扱う作業、正確さが必要な計算や集計そのもの、採用や評価、契約の可否などの判断

計算は表計算ソフトなどで行い、生成AIには計算結果の説明文を書かせる、というように「同じ業務の中の別の工程」で使う形は検討できます。

## よくある業務に当てはめてみる

実際の業務を、工程に分けて当てはめた例です。職場の状況によって答えは変わるので、考え方の見本として見てください。

### 例1 会議の議事録

- 録音の文字起こしを整理する → 条件つき(録音に個人情報や社外秘の話が含まれるなら、扱いを確認してから)
- 決定事項と宿題を抜き出す → 条件つき(出席者が必ず確認する)
- 議事録として配布する → 人が最終確認してから

自分が出席した会議なら、内容の正しさを確かめやすいため、比較的任せやすい業務です。

### 例2 お客様からのクレームへの返信

- 問い合わせ内容の要点を整理する → 条件つき(お客様の名前や連絡先は外して入力する)
- 返信文のたたき台を作る → 条件つき
- 対応方針(返金するか、どこまで謝るか)を決める → 任せない

方針は人が決め、その方針を伝える文章づくりにAIを使う、という分担です。

### 例3 見積書の作成

- 金額の計算 → 任せない(計算は表計算ソフトや見積ソフトで行う)
- 見積の前提条件の説明文を整える → 任せてよい〜条件つき
- 金額を最終決定する → 任せない

### 例4 新しい制度やサービスについての調べもの

- 調べる観点の洗い出し → 任せてよい
- 制度の中身や料金の説明 → 条件つき(必ず公式の発表や一次情報で確認する)
- 自社で使うかどうかの判断 → 任せない

制度や料金は変わることがあります。AIの回答をそのまま使わず、公式の情報で確かめるのが前提です。

## 職場で共有するための判断メモ

判断を毎回頭の中だけで行うと、人によって基準がばらつきます。次のような短いメモを、業務ごとに残しておくのがおすすめです。

```
業務名: 取引先へのお礼メール
任せる工程: 文面のたたき台、敬語の確認
任せない工程: 送信判断
入力しない情報: 取引金額、担当者の個人携帯番号
確認する人: 送信者本人
確認すること: 日付・社名・人名・約束した内容が事実どおりか
```

このメモが何枚かたまると、それ自体が職場の生成AI利用ルールの土台になります。全部の業務を一度に決める必要はありません。よく使う業務から1つずつ書いていけば十分です。

## 迷ったときの最後のひと押し

それでも判断に迷ったら、次の一文で考えてみてください。

「この工程の結果を、AIを使ったと言わずに自分の名前で出せるか」

自分で確かめて責任を持てるなら任せてよい工程です。少しでも不安が残るなら、条件をつけるか、その工程だけは自分で行いましょう。
