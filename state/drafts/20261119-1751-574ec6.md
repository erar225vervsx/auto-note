# 生成AIで資料の構成案を作る 丸投げしない4ステップ

「生成AIに資料を作ってもらったら、見た目は整っているのに中身が使えなかった」。そんな経験はないでしょうか。

見出しはそれらしく並んでいるのに、誰に何を決めてほしい資料なのかがぼやけている。自分の会社の事情とは関係のない一般論が混ざっている。出どころの分からない数字が入っている。結局、ほとんど作り直すことになり、「最初から自分で書いたほうが早かった」と感じてしまう。

この記事では、生成AIを「資料の構成案づくり」に使うときの手順を、プロンプト例つきで紹介します。ポイントは、AIに丸投げせず、**中身は自分、組み立てはAI**と役割を分けることです。社内の提案書、報告資料、説明用スライドなど、どの資料にも使える考え方です。

## なぜ「資料を作って」では使えない構成になるのか

帝国データバンクの2026年の調査では、生成AIを活用する企業の課題として「情報の正確性」を挙げる企業が約半数にのぼりました。資料づくりでも、同じ問題が起きやすくなります。

理由はシンプルで、AIはあなたの資料に必要な情報を知らないからです。

### AIが知らない3つのこと

- **読み手**:部長に見せるのか、現場のメンバーに配るのか、取引先に出すのか
- **目的**:承認してほしいのか、知ってもらえればよいのか、意見がほしいのか
- **手元の事実**:社内の数字、これまでの経緯、すでに決まっていること

この3つが伝わっていないと、AIは「よくある資料の型」と「一般論」で空白を埋めます。ときには、もっともらしい数字や事例まで補ってしまいます。見た目が整っているぶん、どこが補われた部分なのか気づきにくいのが厄介なところです。

### 役割を分けると、作り直しが減る

そこでおすすめなのが、次の分担です。

- **自分がやること**:目的・読み手・結論・事実を決める(中身)
- **AIに任せること**:並べ方の案を出す、抜けや弱いところを指摘する(組み立て)

中身を自分で握っておけば、AIの出力をそのまま信じる必要がなくなります。AIの案は「たたき台」として比べたり選んだりする材料になります。

## 構成案を作る4ステップの全体像

手順は次の4つです。

1. 材料メモを自分で書く(5〜10分)
2. 構成案を複数出してもらい、比べる
3. 選んだ案の各見出しを「言いたいこと1文」に直す
4. 抜けと根拠のない箇所をAIに指摘させ、自分で埋める

順に見ていきましょう。

## ステップ1:材料メモを自分で書く

最初にAIを開くのではなく、メモ帳を開きます。ここが一番大事なステップです。次の5項目を、箇条書きで書き出してください。きれいな文章である必要はありません。

### 材料メモの5項目

- **目的**:この資料で、読み手に何をしてほしいか(承認、理解、意見、行動など)
- **読み手**:誰が読むか。その人が何を知っていて、何を気にしそうか
- **結論**:一番伝えたいことを1〜2文で
- **手元の事実**:使える数字、経緯、決まっていること(出どころもメモ)
- **制約**:ページ数、発表時間、社内の決まった型など

### 例:社内向けの提案資料の場合

たとえば、「紙とExcelで行っている経費精算を、クラウドの経費精算サービスに切り替えたい」という提案を課長会議に出す場面を考えます(説明のための架空の例です)。

- 目的:来期からの試験導入を承認してほしい
- 読み手:各部の課長。現場の手間には関心があるが、費用と移行の負担を気にしそう
- 結論:まず1部署で3か月試し、効果を見てから全社に広げたい
- 手元の事実:自部署で月に何件の申請があるか、差し戻しが何件あったか(自分で数えた数字)、候補サービスの見積もり
- 制約:会議の持ち時間は10分、スライドは10枚程度

この時点で「結論」が書けない場合は、まだ資料を作る段階ではないかもしれません。AIに頼る前に、何を決めてほしいのかを上司や関係者と確認しておくほうが、結果的に早く進みます。

## ステップ2:構成案を複数出してもらい、比べる

材料メモができたら、AIに渡します。ここでのコツは、**1案ではなく複数案を出してもらう**ことです。1案だけだと、それが良いのか悪いのか判断する基準がありません。並べて比べることで、自分の資料に合う流れが見えてきます。

### プロンプト例

```
あなたは社内資料の構成を考えるアシスタントです。
以下の材料メモをもとに、資料の構成案を3つ出してください。

条件:
・3案は、話の順番の考え方が違うものにしてください
 (例:結論から入る/課題から入る/比較から入る)
・各案は見出しを箇条書きで並べ、1行で狙いを添えてください
・材料メモにない事実・数字・事例は追加しないでください
・不足している情報があれば、最後に「確認したいこと」として質問してください

【材料メモ】
(ここにステップ1のメモを貼る)
```

### 比べるときの3つの観点

出てきた案は、次の観点で見比べます。

- **読み手が最初に知りたいことが、最初のほうにあるか**:承認がほしい資料なら、結論と「何を決めてほしいか」が冒頭近くにあるほうが読みやすくなります
- **読み手の心配に答える場所があるか**:例でいえば、費用や移行の負担について触れる見出しがあるか
- **持ち時間・枚数に収まりそうか**:見出しが多すぎる案は、それだけで説明が駆け足になります

AIが最後に「確認したいこと」を質問してきたら、それは材料メモの抜けを教えてくれているサインです。答えられるものは材料メモに書き足しておきましょう。

## ステップ3:各見出しを「言いたいこと1文」に直す

1案を選んだら(複数案の良いところを組み合わせてもかまいません)、次に各見出しを見直します。

AIが出す見出しは「現状の課題」「導入のメリット」「今後のスケジュール」のような、**話題を示すだけの名詞**になりがちです。これを、その章やスライドで**言いたいことを1文にした形**に直します。

### 直し方の例

- 「現状の課題」→「差し戻しの多さが、申請者と経理の両方の手間になっている」
- 「導入のメリット」→「入力ミスの差し戻しを減らせる見込みがある」
- 「今後のスケジュール」→「まず1部署で3か月試し、結果を見て判断したい」

1文にしようとすると、「この章で何を言いたいのか、実は決まっていなかった」と気づくことがあります。それに気づけること自体が、このステップの価値です。

### 1文と根拠をセットにする

さらに、それぞれの1文の横に「根拠は何か」を書いておきます。

- 差し戻しの多さが手間になっている → 根拠:自部署の差し戻し件数(自分で集計)
- 差し戻しを減らせる見込みがある → 根拠:候補サービスの入力チェック機能(公式の説明で確認する)

根拠が書けない見出しは、言い切りすぎているか、まだ調べていないかのどちらかです。そのまま資料にすると、会議で質問されたときに答えられません。

### このステップ用のプロンプト例

```
次の構成案の各見出しを、その章で伝えたいことを1文で言い切る形に書き直してください。

条件:
・材料メモにある事実の範囲で書いてください
・材料メモから言えないことを含む場合は、その見出しの後ろに【要確認】と付けてください
・書き直した1文ごとに、根拠にできる材料メモの項目を示してください

【材料メモ】
(貼る)

【選んだ構成案】
(貼る)
```

AIが【要確認】を付けた箇所は、AIが材料にない内容を想像で補おうとした場所です。ここを放置しないことが、誤った資料を防ぐ一番の近道です。

## ステップ4:抜けと根拠のない箇所を指摘させ、自分で埋める

最後に、AIを「厳しい読み手」として使います。作る役ではなく、**ツッコミ役**です。

### ツッコミ役のプロンプト例

```
あなたは、この資料を読む課長の立場です。
以下の構成案を読んで、次の点を指摘してください。

1. 読んだあとに出そうな質問や反論を5つ
2. 根拠が弱い、または示されていない主張
3. 話の順番で分かりにくいところ

指摘だけをしてください。資料の書き直しはしないでください。
```

「書き直しはしないでください」と添えるのは、AIに直させると、また材料にない内容が混ざる可能性があるからです。指摘を受け取ったら、どう直すかは自分で決めます。

### 指摘を受けたあとの判断基準

- **事実で答えられる質問** → 資料に1行加えるか、補足資料に回す
- **まだ答えを持っていない質問** → 調べる、または関係者に確認する。分からないまま資料に書かない
- **読み手に関係のない指摘** → 採用しない。AIの指摘をすべて取り入れる必要はありません

## 仕上げ前のチェックリスト

構成が固まり、本文やスライドを作ったら、提出前に次の項目を確認します。

- 冒頭で、読み手に何をしてほしいかが分かるか
- 各見出し(スライドのタイトル)が、言いたいことの1文になっているか
- すべての数字に、出どころ(自分の集計、公式の資料など)を答えられるか
- AIが補った事例・数字・固有名詞が残っていないか
- 社外に出せない情報や個人情報を、会社のルールに反してAIに入力していないか
- 持ち時間・枚数に収まっているか

特に3つ目と4つ目は、AIを使った資料で見落としやすいところです。「この数字はどこから来たのか」と自分に聞いて、答えられないものは消すか、確認してから使いましょう。

## よくあるつまずきと対処

### AIの構成がどれも同じような型になる

材料メモの「読み手」と「目的」が抽象的な可能性があります。「上司」ではなく「費用を気にする課長たち」のように、読み手の関心まで書くと、構成案に違いが出やすくなります。

### 見出しを1文にすると長くなりすぎる

1文に複数のことを詰め込んでいるサインです。「〜し、〜で、〜」と続く場合は、章を分けるか、どちらか一方を補足に回しましょう。

### 材料メモを書く時間がない

5項目すべてが埋まらなくても、「目的」と「結論」の2つだけは書いてからAIに渡してください。この2つがあるだけでも、AIの案はかなり絞り込まれたものになります。

## まとめ

生成AIで資料の構成案を作るときは、次の4ステップで進めます。

1. 目的・読み手・結論・事実・制約を、材料メモとして自分で書く
2. 構成案を3つ出してもらい、読み手の目線で比べる
3. 各見出しを「言いたいこと1文」に直し、根拠とセットにする
4. AIをツッコミ役にして抜けを洗い出し、自分で埋める

AIは資料の「並べ方」を考えるのが得意ですが、「何を言うべきか」と「それが本当か」は知りません。中身を自分で握り、組み立てをAIに手伝ってもらう。この分担にするだけで、「見た目は整っているのに使えない資料」はぐっと減ります。

次に資料を作るときは、AIを開く前に、まずメモ帳に5行だけ書いてみてください。
