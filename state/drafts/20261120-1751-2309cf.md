# 生成AI利用ルールを根付かせる 少人数職場の運用テンプレ集

生成AIの利用ルールを作ったのに、気づけば誰も見ていない。
「これ入力していいんだっけ?」という質問が、結局また担当者に集まってくる。

ルールは、作った瞬間がいちばん弱い状態です。
少人数の職場では、規程を整える担当者も、研修を開く余裕もないことが多く、配って終わりになりがちです。

この記事は、以前紹介した「A4一枚の生成AI利用ルール」の続編です。
**作ったルールを職場に根付かせるための運用テンプレート** を、書き換えてそのまま使える形でまとめました。

ルールをまだ作っていない場合も、テンプレートの項目を見れば、何を決めておけばよいかが分かるようにしています。

## ルールが使われなくなる4つの理由

運用がうまくいかない原因は、だいたい次の4つに分けられます。

### 1. 説明されていない

共有フォルダに置いただけでは、多くの人は読みません。
読んでも、自分の仕事のどの場面に当てはまるのかが分からないままになります。

### 2. その場で判断できない

「個人情報は入力しない」と書いてあっても、目の前の資料のどこが個人情報なのか、どう直せば入力してよいのかが分からなければ、使うのをやめるか、そのまま入れてしまうかのどちらかになります。

### 3. 間違えたときの動き方が決まっていない

誤って入力してしまったとき、報告の仕方が決まっていないと、黙っておくほうが楽になります。
報告が遅れるほど、確認や対応は難しくなります。

### 4. 一度作って更新されない

生成AIのサービスは、機能や利用規約、設定画面がよく変わります。
半年前に確認した「学習に使わない設定」が、今も同じ場所にあるとは限りません。

## 運用の全体像:4つの場面にテンプレートを置く

この4つに対応するように、運用を次の場面に分けて考えます。

- **伝える**:説明会、理解度の確認
- **その場で判断する**:置き換え表、仕事の判定シート
- **困ったときに動く**:報告テンプレート、受け手の対応手順、新しいツールの相談シート
- **育てる**:3か月ごとの見直しチェックリスト、よくある質問の記録

ポイントは、ルールそのものを長くしないことです。
ルールはA4一枚のまま、迷う場面ごとに「手元で使う道具」を足していくと、読む量を増やさずに守りやすくできます。

### 運用の前に押さえておきたい公的な注意点

個人情報保護委員会は2023年6月2日に「生成AIサービスの利用に関する注意喚起等」を公表しています。
その中で事業者に対しては、個人情報を含むプロンプトを入力する場合に、利用目的を達成するために必要な範囲内かを十分に確認すること、個人データを含むプロンプトを入力する場合は、サービス提供事業者がそのデータを機械学習に利用しないこと等を十分に確認することが挙げられています。
一般の利用者に向けても、利用規約やプライバシーポリシー等を確認し、入力する情報を踏まえて利用を判断するよう呼びかけています。

以下のテンプレートは、この「入力前に確かめる」「サービスの扱いを確かめる」を、日々の仕事の中で実行しやすくするためのものです。
個人情報や契約上の扱いで判断に迷う場合は、原文を確認したうえで、必要に応じて専門家に相談してください。

ここから先の有料部分では、次の8つのテンプレートを、記入例つきで紹介します。

1. 15分で終わる説明会の進め方(台本)
2. 入力前の置き換え表
3. 仕事の判定シート(3つの質問)
4. 「入力してしまった」ときの報告テンプレート
5. 報告を受けた人の対応手順
6. 新しいツールを使いたいときの相談シート
7. 理解度チェック10問(答えつき)
8. 3か月ごとの見直しチェックリストと、よくある質問の記録表

## テンプレート1:15分で終わる説明会の台本

全員が集まれる朝礼や定例のあとに、15分だけ時間をもらう想定です。
資料は利用ルールのA4一枚だけで足ります。

**0〜2分:なぜルールを作ったか**

> 「生成AIを禁止するためではなく、安心して使えるようにするためのルールです。迷ったときに確認できる場所として使ってください。」

**2〜7分:入力しないものを、実物で確認する**

自社でよく扱う書類(見積書、問い合わせメール、議事録など)を1つ選び、「この部分は入力しない」「ここをこう置き換えれば入力してよい」を画面や紙で一緒に見ます。
抽象的な説明より、実物を1枚見るほうが記憶に残ります。

**7〜10分:使ってよい仕事・条件付きの仕事・使わない仕事**

ルールの区分を読み上げ、「みなさんの仕事だと、どれに当たりそうですか」と1〜2人に聞きます。

**10〜13分:間違えたときの連絡先**

> 「誤って入力してしまったら、すぐに〇〇さんに連絡してください。正直に報告してくれた人を責めることはしません。」

この一言は、必ず責任者の口から伝えてください。

**13〜15分:質問を集める**

その場で出なかった質問は、後日チャットで受け付けます。
集まった質問は、テンプレート8の記録表に書き写します。

## テンプレート2:入力前の置き換え表

「入力しない」だけでなく、「どう直せば入力してよいか」を一覧にした表です。
職場でよく出てくる情報に合わせて行を増やしてください。

| 元の情報 | 置き換え方 | 例 |
|---|---|---|
| 顧客・取引先の会社名 | アルファベットに置き換える | 株式会社〇〇 → A社 |
| 担当者の氏名 | 役割で呼ぶ | 山田様 → 先方の担当者 |
| 社員の氏名 | 役職や記号にする | 佐藤さん → 営業担当B |
| 電話番号・メールアドレス・住所 | 削除する | (入力しない) |
| 具体的な金額 | 必要なければ削除、必要なら「〇万円」「約〇割」など幅を持たせる | 1,280,000円 → 約130万円 |
| 公表前の数字・計画 | 入力しない。構成や言い回しだけ相談する | 「売上報告の文章の型を作って」と頼む |
| 取引先から預かった資料 | 入力しない | (相手の了承と契約内容を確認するまで使わない) |
| パスワード・アクセス情報 | 絶対に入力しない | — |

表の下に、次の一文を添えておくと判断がぶれません。

> 置き換えても、組み合わせると誰のことか分かる場合(例:業界・地域・時期が特定できる)は入力しない。迷ったら〇〇さんに聞く。

## テンプレート3:仕事の判定シート(3つの質問)

ルールの「使ってよい/条件付き/使わない」に当てはまらない仕事が出てきたときに使います。
上から順に答えていきます。

**質問1:入力したい情報に、置き換え表で「入力しない」とした情報は含まれますか?**

- はい → 置き換えるか、その部分を除いてから次へ。除けない場合は **使わない**
- いいえ → 次へ

**質問2:出てきた結果は、社外の人の目に触れますか?(メール、資料、ホームページ、SNSなど)**

- はい → **条件付き**。作った人以外が内容を確認してから出す
- いいえ → 次へ

**質問3:結果をもとに、お金・契約・人の評価・健康・法律に関わる判断をしますか?**

- はい → **判断そのものには使わない**。情報の整理や文章の下書きにとどめ、判断は担当者が行う
- いいえ → **使ってよい**。ただし数字・日付・固有名詞は元の資料で確認する

判定に迷った仕事は、テンプレート8の記録表に書いておき、次の見直しでルールの区分に追加します。

## テンプレート4:「入力してしまった」ときの報告テンプレート

社内チャットに固定しておき、コピーして埋めるだけで報告できるようにします。

> 【生成AI 誤入力の報告】
> ・いつ:〇月〇日 〇時ごろ
> ・使ったサービスとアカウント:(例:〇〇、個人のアカウント)
> ・入力してしまった情報:(例:取引先1社の担当者名と電話番号)
> ・どの書類からか:(例:〇月〇日の問い合わせメール)
> ・会話の履歴は残っているか:はい/いいえ/分からない
> ・気づいたきっかけ:
> ・すでにしたこと:(例:まだ何もしていない)

「何を入れたか」が正確に分かるほど、その後の対応を決めやすくなります。
記憶があいまいな場合は「分からない」と書いてよい、と明記しておきましょう。

## テンプレート5:報告を受けた人の対応手順

報告を受ける側の手順も、事前に決めておきます。慌てると、確認の順番を飛ばしてしまうからです。

1. **お礼を言う**:「報告ありがとう」と最初に伝える。責める言葉は使わない
2. **入力内容を確認する**:報告テンプレートの内容をもとに、どの情報が、どのサービスに入ったかを整理する
3. **サービス側の扱いを確認する**:利用したアカウントの設定(学習への利用の扱い、履歴の保存)を、提供元の公式ヘルプで確認する。履歴の削除方法も確認する
4. **影響を整理する**:誰の、どんな情報か。取引先との契約に関わるか
5. **社内の責任者に共有する**:個人情報や取引先の秘密情報が含まれる場合は、社内の責任者に共有し、法令上・契約上の対応が必要かどうかを、原文や契約書を確認したうえで判断する。判断が難しい場合は専門家に相談する
6. **再発を防ぐ仕組みを1つ決める**:置き換え表に行を足す、会社のアカウントを用意する、など。個人の注意で終わらせない
7. **記録する**:日付・内容・対応・再発防止策を、テンプレート8の記録表に残す

## テンプレート6:新しいツールを使いたいときの相談シート

「一覧にないツールは相談してから使う」とルールに書いても、相談の仕方が分からないと、黙って使われてしまいます。
次の項目を埋めて担当者に送ってもらう形にします。

> 【生成AIツール 利用の相談】
> ・ツール名と提供元:
> ・使いたい仕事:(例:会議の録音から議事録の下書きを作る)
> ・入力する予定の情報:(例:社内会議の音声。取引先は含まない)
> ・無料版か有料版か、個人か会社のアカウントか:
> ・確認した利用規約・ヘルプのページ名と確認日:
> ・入力した内容が学習に使われるかどうか、その設定:(分からなければ「未確認」)

担当者は、確認できた内容と確認日を「使ってよいツール」の一覧に追記します。
**未確認の項目が残っているうちは、置き換え後の情報だけで試す** といった条件付きの許可にしておくと、止めすぎずに済みます。

説明会の翌週などに、チャットやアンケート機能で配ります。
点数をつけることよりも、**間違いが多かった問題を見つけて、ルールや説明を直す** ことが目的です。

1. 取引先の担当者名を「先方の担当者」に置き換えれば、メールの下書きに使ってよい。(○/×)
 → ○(ほかの情報と組み合わせて特定できない場合)
2. 個人のアカウントでも、会社の仕事に使ってよい。(○/×)

3. AIが作った文章に誤りがあった場合、責任はAIの提供元にある。(○/×)
 → ×(使った人が自分の文章として責任を持つ)
4. 社外に出すメールは、作った人以外が確認してから送る。(○/×)
 → ○
5. 採用の合否をAIに判断させてよい。(○/×)
 → ×(判断そのものには使わない)
6. 公表前の売上の数字は、入力してよい。(○/×)

7. 誤って入力してしまったら、まず履歴を消してから、誰にも言わなくてよい。(○/×)
 → ×(すぐに報告する)
8. 一覧にないツールを使いたいときは、相談シートを送る。(○/×)

## テンプレート8:3か月ごとの見直しチェックリストと記録表

### 見直しチェックリスト

見直しの日に、担当者が上から確認します。30分程度を目安にしてください。

- [ ] 使ってよいツールの利用規約・プライバシーポリシーに変更はないか(確認日を更新)
- [ ] 学習への利用の設定画面や、法人向けプランの条件に変更はないか
- [ ] 一覧にないツールを使っている人はいないか(責めずに聞く)
- [ ] 記録表の「よくある質問」のうち、ルールに書き足すべきものはないか
- [ ] 判定シートで迷った仕事を、ルールの区分に追加するか
- [ ] 誤入力の報告と、その再発防止策は実行されているか
- [ ] 理解度チェックで間違いが多かった問題について、説明を直したか
- [ ] 「未決事項」のうち、今回決められるものはないか
- [ ] 新しく入った人・業務委託の人に、ルールを説明したか
- [ ] 改訂した場合、版番号と改訂日を書き換え、全員に知らせたか

### 記録表

1つの表に、質問・迷った仕事・誤入力をまとめて記録すると、見直しのときに一度に確認できます。

| 日付 | 種類 | 内容 | 対応 | ルールへの反映 |
|---|---|---|---|---|
| 〇/〇 | 質問 | 議事録に取引先の発言を入れてよいか | 当面は社内会議のみと回答 | 次回の見直しで検討 |
| 〇/〇 | 迷った仕事 | 求人票の文章作成 | 条件付き(公開前に確認)と判定 | 区分に追加 |
| 〇/〇 | 誤入力 | 問い合わせメールの電話番号 | 履歴を削除、置き換え表に行を追加 | 反映済み |

「種類」は、質問・迷った仕事・誤入力・ツールの相談の4つ程度で十分です。

## 使い始める順番

8つ全部を一度に用意する必要はありません。おすすめの順番は次のとおりです。

1. **最初の週**:置き換え表(テンプレート2)と報告テンプレート(テンプレート4)を、社内チャットに固定する
2. **2週目**:15分の説明会(テンプレート1)を開く
3. **3週目**:理解度チェック(テンプレート7)を配り、間違いが多い問題を確認する
4. **それ以降**:判定シート・相談シートは、迷う場面が出てきたときに配る
5. **3か月後**:見直しチェックリスト(テンプレート8)で、最初の改訂をする

ルールを根付かせるのに必要なのは、立派な文書よりも、迷ったときにすぐ開ける道具と、報告しやすい雰囲気です。
まずは置き換え表と報告テンプレートの2つから、職場のチャットに置いてみてください。
