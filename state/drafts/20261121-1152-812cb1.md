# 生成AIにExcelの数式を頼む 伝え方と確かめ方の手順

「この表から、担当者ごとの今月の売上を合計したい。でも関数の組み合わせ方が分からない」。そんなとき、生成AIに聞くと数式がすぐに返ってきます。

ただ、そのまま貼り付けたらエラーになった、動いたけれど合計が少し合わない、ということも起こります。数式は見た目では正しさが分かりにくく、間違ったまま使い続けてしまうのがいちばん怖いところです。

この記事では、生成AIにExcelの数式を作ってもらうときの「伝え方」と、返ってきた数式を「確かめる手順」をまとめます。関数に詳しくない方でも、明日から同じ流れで使えるように書きました。

## AIが作った数式でつまずく3つのパターン

生成AIが返す数式で困るのは、だいたい次の3つです。

- **貼っても動かない**:列の位置やシート名が実際の表と違う、使っているExcelにない関数が入っている、など。
- **動くけれど答えが違う**:空白のセルや、同じ名前の重複、数字に見える文字列などを想定していない。
- **自分の環境では動くが、相手の環境で動かない**:新しい関数を使ったブックを、古いバージョンのExcelで開いた場合など。

たとえばXLOOKUP関数は、Microsoft 365やExcel 2021以降で使える関数です。それより古いExcelでブックを開くと、その関数を入れたセルはエラー(多くは #NAME?)になることがあります。取引先や社内の別の人がどのExcelを使っているかで、同じ数式でも結果が変わるということです。

どれも、AIが「あなたの表」と「あなたの環境」を知らないまま答えていることが原因です。つまり、伝える情報を少し増やすだけで、かなり防げます。

## 頼む前にそろえる4つの情報

依頼文を書く前に、次の4つをメモしておきます。

### 1. やりたいことを「入力」と「結果」で書く

「売上を集計したい」ではなく、「B列の担当者名ごとに、D列の金額を合計して、別シートの一覧に表示したい」のように、どの列を使って、どこに何を出したいかを書きます。

### 2. 表の形(列・見出し・範囲)

見出しが何行目にあるか、データが何行目から何行目まであるか、列ごとに何が入っているかを書きます。「A列:日付、B列:担当者、C列:商品名、D列:金額。見出しは1行目、データは2行目から」といった書き方で十分です。

### 3. 使っているExcelと、ブックを開く人の環境

「Microsoft 365のExcel(Windows)」「Excel 2016」など、分かる範囲で書きます。分からない場合は、「古いバージョンでも動く関数で」と一言添えるだけでも違います。ブックを社外に渡すなら、そのことも伝えます。

### 4. 例外のときにどうしたいか

ここがいちばん抜けやすいところです。

- 該当するデータがないときは、空白にするか、0にするか、「該当なし」と出すか
- 金額が空白の行はどう扱うか
- 同じ担当者名が全角・半角やスペースの有無で表記ゆれしていないか

例外の扱いを決めずに頼むと、AIは「よくある前提」で数式を作ります。その前提が自分の表と合っているかは、こちらで決めるしかありません。

## 実データは貼らず、ダミーの表で伝える

数式を作ってもらうのに、本物のデータは必要ありません。顧客名や金額をそのまま貼り付けるのは避けましょう。生成AIのサービスによっては、入力した内容が既定の設定でサービスの改善に使われる場合があります。会社のルールや、使っているサービスの設定も確認しておきましょう。

代わりに、列の構成だけ同じにした小さな表を作って伝えます。

- 担当者名は「担当A」「担当B」のように置き換える
- 金額は「1000」「2500」など、あとで手計算しやすい数字にする
- 行数は5〜10行ほどで十分
- 例外(空白、重複、該当なし)をわざと1行ずつ入れておく

このダミーの表は、あとで数式を確かめるときのテスト用の表としても使えます。最初に作っておくと、二度手間になりません。

## そのまま使える依頼文の型

上の4つの情報を、次の型に当てはめます。

```
Excelの数式を作ってください。

【やりたいこと】
「売上」シートのB列(担当者)ごとに、D列(金額)を合計し、
「集計」シートのB列に表示したい。
「集計」シートのA列には担当者名が並んでいる。

【表の形】
「売上」シート:A列 日付、B列 担当者、C列 商品名、D列 金額
見出しは1行目、データは2行目から(行数は毎月増える)

【環境】
Microsoft 365のExcel(Windows)。
ブックはExcel 2016を使う人も開く。

【例外の扱い】
・該当する売上がない担当者は0と表示
・金額が空白の行は無視する
・担当者名の全角・半角やスペースの違いは、同じ人として扱いたい

【お願い】
・数式は1つに絞り、各部分が何をしているか日本語で説明してください
・前提にしていることがあれば、最後に書き出してください
・下の表で正しく動くか、期待される結果も示してください

(ここにダミーの表を貼る)
```

ポイントは最後の【お願い】です。「説明」「前提の書き出し」「期待される結果」の3つを頼むと、次の確認作業がぐっと楽になります。

たとえば、この依頼に対しては次のような数式が返ってくることがあります(「集計」シートのB2に入れる例です)。

```
=SUMIFS(売上!D:D,売上!B:B,A2)
```

SUMIFS関数は条件に合う行だけを合計する関数で、Excel 2016でも使えます。列全体(D:D、B:B)を指定しているので、データが増えても集計から漏れません。ただし、名前の後ろに余分なスペースが入っているだけでも別の名前として扱われます。依頼文に書いた「担当者名の全角・半角やスペースの違いは、同じ人として扱いたい」という条件を、この数式が満たしているかは、AIの説明と実際の結果で確かめる必要があります。満たしていなければ、その点を伝えて直してもらいます。ただ、表記ゆれを数式の中で吸収しようとすると数式が複雑になりがちです。先に元データの表記をそろえておく(「検索と置換」で直す、またはTRIM関数・ASC関数を使った補助列を作る)ほうが、数式は簡単で確かめやすくなります。こうした食い違いを見つけるのが、次の確認作業です。

## 返ってきた数式を確かめる5つの手順

数式が返ってきたら、本番の表に貼る前に、次の順に確かめます。

### 手順1 説明を読んで、自分の言葉で言い直す

AIの説明を読み、「この数式は、B列が担当Aの行だけ選んで、D列を足している」のように、自分の言葉で言い直せるか試します。上の例なら「売上シートのB列がA2の名前と同じ行だけ選んで、D列を足している」と言えれば十分です。言い直せない部分があれば、「この部分は何をしていますか」と聞き返します。分からないまま使わないことが、いちばんの予防策です。

### 手順2 前提が自分の表と合っているか見る

AIが書き出した前提を読みます。「見出しは1行目」「データは1000行目まで」「担当者名は完全一致」など、自分の表と違う前提があれば、その点を伝えて作り直してもらいます。特に、範囲の終わりが決まった行数(たとえば2行目から100行目まで)になっていると、データが増えたときに集計から漏れます。列全体を指定した数式に直してもらうか、自分で表を「テーブル」にしたうえで、テーブルを使った数式に書き直してもらいましょう。テーブルは、表を選んで「ホーム」タブの「テーブルとして書式設定」(またはCtrl+T)で作れ、行を足すと範囲が自動で広がります。

### 手順3 ダミーの表で、答えが分かっている計算と比べる

用意したダミーの表に数式を入れて、手計算した答えと一致するかを見ます。

- 普通の行だけのケース
- 金額が空白の行を含むケース
- 該当するデータがない担当者のケース
- 同じ担当者が何行もあるケース

AIが示した「期待される結果」も参考になりますが、それ自体が間違っていることもあります。答え合わせの基準は、必ず自分で計算した数字にしてください。

### 手順4 Excelの確認機能を使う

Windows版のExcelには、数式を1段階ずつ計算して途中の値を確かめる「数式の検証」という機能があります(バージョンによって表示名が少し異なることがあります)。「数式」タブの「数式の監査」グループにあり、同じグループに「エラー チェック」も並んでいます。複雑な数式で、どこで値がおかしくなるかを探すのに便利です。

「エラー チェック」では、数式の問題を探すことができます。ただし、Microsoftのサポートページでも、このチェックですべてのエラーが見つかるわけではないとされています。エラーが出ないことは、答えが正しいことの証明にはなりません。

### 手順5 本番の表で、一部だけ別の方法で突き合わせる

本番の表に入れたら、担当者を1〜2人選び、別の方法で出した数字と比べます。たとえば、担当者の列でフィルターをかけてその人の行だけを表示し、金額の列を選択すると、画面右下(ステータスバー)に合計が表示されます。この数字と、数式の結果を見比べます。数式とは違う方法で同じ答えになれば、安心して使えます。

## よくあるつまずきと、AIへの伝え直し方

確かめる途中でおかしな点が見つかったら、「動きません」とだけ伝えるより、何が起きたかを具体的に返すと、直った数式が返ってきやすくなります。

- **エラーが表示された**:表示されたエラーの文字(例:#N/A)と、どのセルで出たかを伝える。
- **数式を下にコピーしたら参照がずれた**:「下の行にコピーして使う」と伝える。コピーしてもずれない書き方(「$」を付けた参照)や、列全体の指定、テーブルを使う書き方にしてもらいます。なお「$」はコピー時のずれを防ぐもので、データが増えたときの漏れは防げません。
- **合計が少し合わない**:合わなかった担当者と、手計算の値・数式の値の両方を伝える。表記ゆれや、文字列として入った数字が原因のことがあります。
- **古いExcelでエラーになった**:開いた人のバージョンを伝え、その環境で使える関数での書き直しを頼む。

AIとのやりとりは、1回で正解を引くものではなく、確認しながら2〜3往復で仕上げるものだと考えておくと気が楽です。

## AIに頼んでよい場面・慎重にすべき場面

数式づくりは、生成AIが役に立ちやすい作業です。ただ、表の用途によって確認の手間のかけ方を変えます。

- **自分用の集計・下書き**:上の手順1〜3まで確認すれば、まずは十分です。
- **社内で共有する資料の数字**:手順5の突き合わせまで行い、相手のExcelのバージョンも確認します。
- **請求・給与・会計など、間違いが直接お金や信用に関わる表**:AIの数式をそのまま採用せず、Excelに詳しい人や担当部署にも確認してもらいます。

また、合計や平均といった計算そのものをAIの回答欄でさせるのは避けましょう。生成AIは計算を間違えることがあります。AIには「数式を作ってもらう」、計算は「Excelにさせる」と役割を分けるのが安全です。
