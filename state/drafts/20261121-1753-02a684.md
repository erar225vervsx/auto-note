# 生成AIの出力チェックリスト 業務別8枚と点検プロンプト

生成AIの回答を仕事で使うとき、「どこまで確認すればいいのか」で毎回迷っていませんか。この記事では、業務8つ分のチェックリストと、コピーして使える点検用の依頼文をまとめました。

メールのときは宛名を見て、議事録のときは数字を見て……と、そのつど思いついた所だけを見ていると、見落としが出ます。しかも確認のしかたが人によって違うので、チームで使うと品質がそろいません。

帝国データバンクが2026年3月に行い、約1万社が回答した調査でも、生成AIの懸念として「情報の正確性」を挙げた企業が約半数(複数回答)にのぼりました。使うかどうかだけでなく、「どう確かめるか」が課題になっています。

無料部分では、確認の全体像、どの業務でも使える共通の5項目と下見用の依頼文、確認の深さを決める判断基準を紹介します。有料部分には、次の8業務のチェックリストと、AI自身に下見をさせる業務別の点検依頼文(プロンプト)を、そのままコピーして使える形で載せています。

- 社外メール
- 議事録
- 長い資料の要約
- 資料の構成案・スライド原稿
- Excelの数式
- 社内のお知らせ・案内文
- 調べものの回答(情報収集)
- 英文メール・翻訳

## 確認が毎回バラバラになる理由

確認がうまくいかない原因は、注意力の不足ではなく、「何を見るか」が決まっていないことにあります。

生成AIの文章は言い回しが自然なぶん、間違いがあっても目に留まりにくく、読み流すと「よさそう」に見えてしまいます。見る場所を先に決めておくことが大切です。

もう一つは、業務によって間違いやすい場所が違うことです。例えば次のとおりです。

- **社外メール**:宛名・日時・金額などの、相手に送ると取り消せない情報
- **議事録**:発言者の取り違えや、決まっていないことが「決定」と書かれること
- **要約**:元の資料にない内容が混ざることや、大事な条件が抜けること
- **Excelの数式**:参照する範囲のずれや、空欄・文字が混じったときの動き

だから、業務ごとにチェックリストを用意しておくのが近道です。

## チェックリストの全体像(3段の確認)

この記事のチェックリストは、次の3段で使う前提で作っています。

1. **AIに下見をさせる**:書かせたあと、同じ会話の中で点検用の依頼文を送り、AI自身に怪しい箇所を挙げさせる
2. **共通の5項目を見る**:どの業務でも必ず見る項目を、人が確認する
3. **業務別の項目を見る**:その業務で間違いやすい所を、人が確認する

1段目の下見は、「見る場所の候補を出してもらう」ためのものです。AIが「問題ありません」と答えても、確認は終わりではありません。最終的に確かめるのは、元の資料や公式の発表など、もとになった情報を見られる人です。

## どの業務でも使える共通の5項目

まずは、業務を問わず毎回見る5項目です。これだけでも、見落としを防ぎやすくなります。

### 1. 固有名詞は正しいか

人名・社名・部署名・商品名・地名を、元の資料や名刺、社内の名簿と見比べます。AIはもっともらしい表記に直してしまうことがあるので、「見たことがある名前だから大丈夫」とは考えないようにします。

### 2. 数字・日付・金額は元の情報と合っているか

数字は1つずつ、元の資料と照らし合わせます。日付は曜日も合わせて確認します。単位(円・千円・%など)の取り違えもよく起きるので、桁と単位をセットで見ます。

### 3. 元の情報にないことが書かれていないか

AIは、話の流れを自然にするために、元の資料にない説明や理由を足すことがあります。「この一文はどこに書いてあったか」を言えない文は、削るか、確かめてから残します。

### 4. 言い切りすぎていないか

「必ず」「絶対に」「〜が義務です」のような強い言い方は、根拠があるときだけ使います。根拠が確かめられないときは、弱めるか削ります。法律・税・医療・お金に関わる内容は、専門家や担当部署に確認します。

### 5. 外に出して困る情報が入っていないか

社外に出す文章に、社内向けの情報(原価、ほかの取引先の名前、個人の連絡先など)が混ざっていないかを見ます。AIに入力した資料の内容が、そのまま出力に残っていることがあります。

あわせて、そもそも機密情報や個人情報をAIに入力してよいかは、社内のルールで確かめておきます。ルールがない場合は、入力しないのが安全です。

## どの業務でも使える下見用の依頼文

1段目の「AIに下見をさせる」には、次の依頼文が使えます。出力を作らせた同じ会話に、そのまま貼り付けて送ります。

```
今作成した文章を、点検役として読み直してください。
次の点について、問題がありそうな箇所を本文から抜き出して挙げてください。
1. 固有名詞・数字・日付・金額のうち、私が伝えた情報や資料と照らし合わせるべきもの
2. 私が伝えた情報や資料にない内容が追加されている箇所
3. 根拠がないのに言い切っている箇所
問題がなければ「なし」と書き、推測で直さず、箇所の指摘だけにしてください。
```

会話が長くなると、AIが前半の内容を正しく踏まえられないことがあります。長い資料を扱ったときは、元の資料をもう一度貼り付けてから依頼すると、見落としが減ります。

## 確認の深さを決める判断基準

すべての出力を同じ深さで確認していると、時間がいくらあっても足りません。次の2つの質問で、確認の深さを決めます。

- **質問1:社外の人が読むか、または記録として残るか**(議事録・社内規程の案内なども「はい」とします)
- **質問2:数字・日付・固有名詞・約束ごとが含まれるか**

この答えで、確認の深さを3段階に分けます。

- **両方「はい」**:3段すべて行う。数字と固有名詞は元の資料と1つずつ照合する。可能なら別の人にも見てもらう
- **どちらか一方が「はい」**:下見用の依頼文と共通5項目は必ず行う。業務別の項目は、質問で「はい」になった部分(社外向けの表現、または数字・固有名詞)に関わる項目だけ見る
- **両方「いいえ」**:共通5項目をざっと見る(社内の下書き・アイデア出しなど)

迷ったときは、深いほうを選びます。社外に出た誤りは取り消せないからです。

ここまでの内容だけでも、明日からの確認の抜けは減らせるはずです。

## 有料部分の使い方

ここからは業務ごとに、次の2つを1組にして載せています。共通5項目は毎回見る前提なので、ここでは業務ごとに追加で見る項目だけを挙げています。

- **人が見るチェック項目**:AIの答えを参考にしつつ、人が元の資料と照らし合わせて確かめる項目です。AIが「問題なし」と答えた点も、確かめる対象から外しません


## チェックリスト1:社外メール

### AIへの点検依頼文

```
今作成したメールを、送信前の点検役として読み直してください。
次の点について、問題がありそうな箇所を本文から抜き出して挙げてください。
1. 宛名・社名・日時・金額・数量など、間違えると取り消せない情報
2. 私が伝えた情報にない内容(約束・条件・理由など)が追加されていないか
3. 相手が読んで「何をすればいいか」が分からない箇所
4. 失礼、またはなれなれしく感じられる表現
問題がなければ「なし」と書き、推測で直さず、箇所の指摘だけにしてください。
```

### 人が見るチェック項目

- 宛先(To・CC)と本文の宛名が一致しているか
- 日時は曜日まで正しいか。相手の都合を確認する前に、日時を決めた書き方になっていないか
- 自分が約束していない条件(納期・値引き・対応範囲)が書かれていないか
- 依頼したいことが、本文の前半で分かるか
- 添付すると書いたファイルを、実際に添付したか

## チェックリスト2:議事録

### AIへの点検依頼文

```
今作成した議事録を、元のメモ(または文字起こし)と比べて点検してください。
次の点を、議事録の該当箇所と元の記録の該当箇所を並べて挙げてください。
1. 元の記録にない発言・決定事項が書かれている箇所
2. 「決定」と書かれているが、元の記録では検討中・保留だった可能性がある箇所
3. 発言者が特定できない、または取り違えている可能性がある箇所
4. 担当者・期限が書かれていない宿題(ToDo)
判断がつかないものは「要確認」としてください。
```

### 人が見るチェック項目

- 決定事項は、会議の場で本当に決まったことだけか
- 宿題(ToDo)ごとに、担当者と期限がそろっているか
- 発言者の名前と役職は正しいか
- 数字(予算・件数・日付)は、会議資料と合っているか
- 出席していない人が読んでも、何が決まったか分かるか

## チェックリスト3:長い資料の要約

### AIへの点検依頼文

```
今作成した要約を、元の資料と比べて点検してください。
1. 要約にあるが、元の資料に書かれていない内容を挙げてください。
2. 元の資料にある「条件」「例外」「期限」「金額」のうち、要約から抜けているものを挙げてください。
3. 元の資料では断定していないのに、要約で言い切っている箇所を挙げてください。
それぞれ、元の資料のどの部分に当たるか(見出しやページ)を添えてください。
```

### 人が見るチェック項目

- 要約の結論は、元の資料の結論と同じ向きか
- 「ただし」「〜の場合を除く」などの条件が抜けていないか
- 数字は元の資料と一致しているか(四捨五入で意味が変わっていないか)
- 要約だけを読んだ人が、誤った判断をしそうな箇所はないか
- 元の資料の日付や版が新しいものか
- AIが示した場所(見出し・ページ)は、元の資料で開いて確かめたか

## チェックリスト4:資料の構成案・スライド原稿

### AIへの点検依頼文

```
今作成した構成案を、資料を読む【相手の立場:例 部長・取引先の担当者】の目で点検してください。
1. 相手が最初に知りたいこと(結論・お願い)が、前半にあるか
2. 根拠のない主張や、確認が必要なデータが入っている箇所
3. 順番が飛んでいて、話がつながらない箇所
4. 削っても伝わる、重なっているスライド
推測で数字を補わず、「データが必要」と書いてください。
```

### 人が見るチェック項目

- この資料で相手にしてほしいこと(承認・判断・理解)が、1文で言えるか
- スライドに載せる数字・グラフの出どころを、すべて言えるか
- AIが仮に入れた数字や事例が、そのまま残っていないか
- 社外向けの場合、社内用語や略語をそのまま使っていないか

## チェックリスト5:Excelの数式

### AIへの点検依頼文

```
今提案してくれた数式について、次の点を説明してください。
1. 参照しているセル範囲と、その範囲を選んだ理由
2. 空欄・文字・0・エラー値が範囲に含まれたとき、結果がどうなるか
3. 行を追加したり、数式を下にコピーしたりしたとき、範囲がずれる可能性
4. 私のExcelの環境【例 Microsoft 365/Excel 2016】で使えない関数が含まれていないか
分からない点は「不明」と書いてください。
```

### 人が見るチェック項目

- 答えが分かっている数件で、手計算(または電卓)の結果と一致するか
- 空欄や「-」などが入った行で、思った通りの結果になるか
- 下の行にコピーしたとき、参照がずれていないか(範囲を固定したいときは「$A$2:$A$100」のように $ を付ける「絶対参照」にする)
- 関数名のエラー(#NAME? など)が出ていないか
- 数式の意味を、自分で説明できるか(説明できない数式は使わない)

## チェックリスト6:社内のお知らせ・案内文

### AIへの点検依頼文

```
今作成したお知らせを、初めて読む社員の立場で点検してください。
1. 「いつまでに・誰が・何をするか」が分からない箇所
2. 読む人によって受け取り方が変わりそうな、あいまいな表現
3. 私が伝えた情報にない、規則や手続きの説明が追加されていないか
4. 問い合わせ先が書かれているか
問題がなければ「なし」と書き、推測で直さず、箇所の指摘だけにしてください。
```

### 人が見るチェック項目

- 期限・対象者・手続きの方法が、元の決定内容と一致しているか
- 社内規程や手続きの説明を、AIが一般論で補っていないか(規程は原文で確認する)
- 問い合わせ先の名前・内線番号・メールアドレスは正しいか
- 対象外の人が読んで、自分も対象だと誤解しないか

## チェックリスト7:調べものの回答(情報収集)

### AIへの点検依頼文

```
今の回答について、点検のために次のことをしてください。
1. 回答の中の事実(数字・日付・制度名・固有名詞)を、箇条書きで一覧にしてください。
2. それぞれについて、確かめるならどこを見ればよいか(公式サイト・公的機関の資料など、情報の種類)を書いてください。
3. 情報が古くなっている可能性があるもの、地域や条件で変わるものに印を付けてください。
URLは、確かでない場合は書かないでください。
```

### 人が見るチェック項目

- 事実の一覧の中で、仕事に使うものを、公式の情報で1つずつ確かめたか
- 情報の日付(いつ時点の情報か)を確認したか
- AIが示した出典やURLを、実際に開いて内容を確かめたか(存在しない場合もあります)
- 法律・税・医療・お金に関わる内容は、専門家や担当部署に確認したか

## チェックリスト8:英文メール・翻訳

### AIへの点検依頼文

この1枚だけは、英文を作った会話ではなく、**新しい会話**に英文だけを貼り付けて使います。同じ会話では、AIが元の日本語を踏まえて訳してしまい、意味のずれが見つかりにくくなるためです。

```
次の英文を、日本語に訳してください。
訳したあと、数字・日付・金額・固有名詞の表記を一覧にしてください。
また、相手との関係【例 初めての取引先/長年の担当者】に対して、丁寧すぎる・くだけすぎる表現があれば挙げてください。
推測で直さず、指摘だけにしてください。
【ここに英文だけを貼り付ける】
```

訳された日本語を、自分で元の日本語と見比べます。

### 人が見るチェック項目

- 訳し直した日本語が、伝えたい内容と同じか
- 日付の書き方(月と日の順番)で、相手が誤解しないか
- 金額の通貨と桁が正しいか
- 依頼・お断りなど、大事な一文の意味が弱まったり強まったりしていないか

## コピー用:8枚の要点一覧

印刷やチャットでの共有用に、各チェックリストの「人が見る項目」の要点を1行ずつまとめました。

- **社外メール**:宛先と宛名/日時と曜日/約束していない条件/依頼が前半にあるか/添付の有無
- **議事録**:決定事項は本当に決まったか/ToDoの担当者と期限/発言者名/数字/欠席者が読んで分かるか
- **長い資料の要約**:結論の向き/条件・例外の抜け/数字/誤った判断を招く箇所/資料の日付・版
- **構成案・スライド**:相手にしてほしいこと/数字の出どころ/仮の数字の残り/社内用語
- **Excelの数式**:手計算との一致/空欄の行/コピー後の参照/エラー表示/自分で説明できるか
- **社内のお知らせ**:期限・対象者・手続き/規程は原文で確認/問い合わせ先/対象外の人の誤解
- **調べものの回答**:事実を公式情報で確認/情報の日付/出典を実際に開く/専門分野は専門家へ
- **英文メール・翻訳**:新しい会話で訳し直す/日付の順番/通貨と桁/大事な一文の強さ

## チームで使うときのコツ

チェックリストは、一人で使うより、チームで同じものを使うほうが効果が出ます。始めるときは、次の順番がおすすめです。

1. **よく使う業務を2つだけ選ぶ**:8枚すべてを一度に始めると続きません。使う回数の多い業務から始めます
2. **自分たちの言葉に直す**:社名・部署名・よくあるミスを項目に足し、使わない項目は削ります
3. **置き場所を1つに決める**:共有フォルダやチャットの固定メッセージなど、すぐ開ける場所に置きます
4. **見落としが出たら、項目を足す**:誤りが見つかったときは、誰かを責めるのではなく、チェックリストに1行追加します

## まとめ

AIの「問題なし」はゴールではなく、人が確かめる場所の目印です。確認の手順が決まっていれば、迷いは減らせます。まずは、明日いちばん使う業務のチェックリストを1枚、手元に置くところから始めてみてください。
