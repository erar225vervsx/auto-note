# 生成AIに文章の校正を頼む 直されすぎを防ぐ5つの手順

報告書やお知らせ文を生成AIに「校正して」と頼んだら、返ってきた文章が別物になっていた。そんな経験はありませんか。

誤字を直してほしかっただけなのに、言い回しが全部変わっている。わざと短く切った文が「不適切」と指摘される。どこを直したのか分からず、結局は元の文章と見比べることになる。

この記事では、生成AIに校正を頼むときに「直されすぎ」と「見落とし」を防ぐ手順を、そのまま使える依頼文とあわせて紹介します。ChatGPT、Claude、Gemini など、どのツールでも使える内容です。

## なぜ「校正して」だけだと直されすぎるのか

生成AIは、頼まれた文章を「より自然に見える文」に近づけようとします。ただ、自然に見える文が、あなたの意図に合っているとは限りません。

ITmedia ビジネスオンライン、SHIFT AI、マネーフォワード クラウドの解説記事でも、次のような失敗が挙げられています。

- **指摘しなくてよい所まで直す**:「だ・である調」を「です・ます調」に変える、意図して使った体言止めまで指摘する
- **意味が変わる**:主語と述語の関係が入れ替わる、言い切りが弱まる、逆に強まる
- **言葉そのものを変える**:社内の呼び名、製品名、専門用語、数値が別の表現に置き換わる
- **個性が消える**:無難で平均的な言い回しになり、書き手らしさや会社のトーンがなくなる

原因の多くは、依頼があいまいなことです。「チェックして」とだけ伝えると、AIは何をどこまで直してよいか分からないまま、思いつく改善を全部出してきます。

そこで大事なのが、**「校正」と「書き直し(リライト)」を分けて頼む**ことです。誤りを直してほしいのか、文章をよくしてほしいのか。これを最初に決めるだけで、返ってくる結果が大きく変わります。

## 手順1:直してよい範囲と読み手を決める

AIに渡す前に、自分の中で次の2つを決めておきます。

- **文書の種類と読み手**:社外向けのお知らせ、上司への報告書、社内チャットの連絡など
- **直してよい範囲**:誤字脱字だけか、敬語や言い回しまでか、構成まで見てほしいか

迷ったら、まずは「誤字脱字・文法の誤りだけ」から始めるのがおすすめです。範囲が狭いほど、AIの修正を確認する手間も小さくなります。

読み手を伝えることも効果があります。たとえば「読み手は社内の担当者で、専門用語は通じる」と書いておくと、用語を一般向けに言い換える余計な修正が減ります。

## 手順2:変えてはいけない言葉をリストにする

AIは、あなたの会社の正式名称や社内ルールを知りません。そのため、正しい言葉を「より一般的な言葉」に置き換えてしまうことがあります。

依頼文には、変えてほしくない言葉をはっきり書きます。

- 会社名・部署名・製品名・サービス名
- 人名と肩書き
- 数値・金額・日付・時刻
- 社内で決まった表記(例:「お客様」か「お客さま」か)
- 業界の専門用語

全部を書き出すのが大変なら、「固有名詞と数値は一切変更しないでください」とまとめて伝えるだけでも違います。

なお、社外秘の情報や個人情報が含まれる文章は、そのまま貼らないでください。名前や金額を伏せてから渡すか、会社の利用ルールで認められたツールだけを使いましょう。

## 手順3:修正箇所の一覧と理由を出させる

直されすぎを防ぎ、確認の手間も大きく減らせる工夫がこれです。

修正後の全文だけを受け取ると、どこが変わったのかを自分で探すことになります。これでは見落としが起きやすく、確認にも時間がかかります。

そこで、**修正前・修正後・理由を、1か所ずつ一覧で出させます**。一覧があれば、1件ずつ「採用する/しない」を判断するだけで済みます。

さらに、「迷う箇所は直さずに、指摘だけにしてください」と添えておくと、AIが勝手に判断して書き換えることを減らせます。

### そのまま使える依頼文(誤字脱字・文法だけ)

```
次の文章を校正してください。

・文書の種類:取引先へのお知らせメール
・読み手:取引先の担当者
・直してよい範囲:誤字脱字、文法の誤り、敬語の誤りのみ
・守ること:文意を変えない。言い回しや文体は変えない。固有名詞・数値・日付は一切変更しない
・迷う箇所は修正せず、指摘のみにする
・出力:修正箇所の一覧のみ。番号をつけ、1件ずつ「修正前/修正後/理由」を書く。全文はまだ出さない

(ここに文章を貼る)
```

依頼文の「文書の種類」「読み手」「直してよい範囲」を入れ替えれば、報告書や社内文書にも使えます。

### 採用する修正だけを反映させる

一覧を見て、採用する修正の番号を決めたら、続けて次のように頼みます。

```
番号1・3・4の修正だけを、元の文章に反映した全文を出してください。それ以外の箇所は1文字も変えないでください。
```

最初から全文を出させると、採用しなかった修正まで入った文章ができてしまいます。一覧で選んでから全文を出させる、この順番が大切です。修正が数か所なら、AIの全文を使わず、自分で元の文章に手で直してもかまいません。

## 手順4:余計な指摘が出たら「注意点」として足す

1回目の結果を見ると、たいてい「それは直さなくていい」という指摘がいくつか混ざっています。

ここで、そのまま捨てるのではなく、**依頼文に注意点として書き足します**。たとえば次のような一文です。

- 体言止めはすべて直す必要はありません。使いすぎている場合だけ指摘してください
- 「〜と考えます」という言い方は意図的なので、変えないでください
- 一文が長めなのは許容します。100字を超える文だけ指摘してください(字数の目安は自社の基準に合わせて決めてください)

こうして育てた依頼文は、同じ種類の文書を校正するときに使い回せます。よく使う文書ごとに1つずつ保存しておくと、毎回ゼロから考えずに済みます。

## 補足:大事な文書は観点を分けて頼む

長い文章や大事な文書では、一度に全部を見てもらうより、観点を分けて頼むほうが確認しやすくなります。

- **1回目**:誤字脱字・文法・敬語
- **2回目**:表現(分かりにくい言い回し、同じ言葉の繰り返し、表記ゆれ)
- **3回目**:内容(話のつながり、前後で矛盾していないか)
- **4回目**:読み手の視点(初めて読む人が引っかかる所はどこか)

3回目と4回目は、文章を直させるのではなく「指摘だけ」をもらう使い方が向いています。直すかどうかは、自分で決めます。

## 手順5:送る前に人が確かめる

AIの修正を反映したら、送る前に自分の目で確認します。全文を読み返すのが基本ですが、特に次のポイントは必ず見てください。

- **主語と述語**:誰が何をするのかが、元の文と同じか
- **固有名詞**:社名、人名、製品名が正しいまま残っているか
- **数値と日付**:金額、件数、日時が1文字も変わっていないか
- **言い切りの強さ**:「予定です」が「決定しました」になるなど、約束の度合いが変わっていないか
- **トーン**:必要以上に硬く、あるいは軽くなっていないか

注意したいのは、**AIが一覧に載せずに文章を変えることもある**という点です。「1文字も変えないで」と頼んでも、数値や言い回しが黙って変わっている可能性は残ります。

そこで、元の文章とAIが出した全文を、機械的に見比べる方法も使いましょう。Word の「比較」機能(校閲タブにあります。メール本文なら、元の文と修正後の文をそれぞれWordに貼って保存してから比べます)を使うか、2つの文章の違いを色分けして表示する差分チェックのツールを使えば、変わった所をもれなく確認できます。手で直した場合でも、最後にもう一度全文を読み返してください。

社外に出す文書、契約や金額に関わる文書は、AIの校正を「一次チェック」と位置づけて、最終確認は必ず人が行うようにしましょう。可能であれば、別の人にも一度読んでもらうと安心です。

## こんな使い方は避けたほうがよい

最後に、校正でAIを使うときに避けたい使い方をまとめます。

- **修正後の全文だけを受け取って、そのまま送る**:どこが変わったか分からないまま送ることになります
- **「完璧にして」「プロの文章に」と頼む**:校正ではなく書き直しになり、意味やトーンが変わりやすくなります
- **「極めて丁寧に」など強い指示を出す**:敬語が重なって、かえって不自然な文になることがあります
- **社内ルールの判断まで任せる**:会社独自の表記ルールや言葉の使い分けは、AIには分かりません
- **AIの指摘をすべて正しいと思う**:指摘はあくまで提案です。採用するかは自分で決めます
