# 生成AIで英文メールを作る 誤解を防ぐ確認6ステップ

英語が苦手でも、生成AIで作った英文メールの中身は、日本語だけでかなりの部分まで確かめられます。

海外の取引先へのメールを生成AIに頼むと、それらしい英文がすぐに返ってきます。けれど英語に自信がないほど「この英文で本当に合っているのか」が分からず、送信ボタンを押す手が止まってしまいます。

この記事では、意味の取り違えや失礼な言い回しを防ぐための確認手順を6つのステップで紹介します。どれも、英語を読みこなせなくてもできる方法です。

## なぜ英文メールは「読めたつもり」で事故が起きるのか

生成AIの英文は文法がなめらかで、自然に見えます。だからこそ、間違いに気づきにくいという弱点があります。翻訳の解説記事などでよく挙げられる注意点は、次のようなものです。

- **訳抜け**:原文の一文や条件が、訳文から抜け落ちる
- **意味の逆転**:「〜しない」「〜を除く」などの打ち消しが正しく訳されず、意味が反対になる
- **数字・日付・固有名詞の誤り**:金額や日付、会社名・製品名が変わってしまう
- **原文にない補足**:気をきかせたつもりで、AIが原文にない条件や説明を足してしまう
- **丁寧さのずれ**:内容は合っていても、言い方が強すぎたり、逆に弱すぎて意図が伝わらなかったりする
- **用語のぶれ**:同じ製品名や社内用語が、文によって違う英語になる

どれも、英文をざっと眺めるだけでは見落としやすいものです。そこで、「見る場所」と「確かめ方」を先に決めておきます。

## 送る前の確認6ステップ

### ステップ1:日本語の原文を「訳しやすく」整える

いちばん効くのは、AIに渡す前の日本語を整えることです。日本語のメールは主語を省いたり、遠回しに書いたりすることが多く、そのまま訳すと意図がぼやけます。

次の4点を直してから渡します。

- **主語を書く**:「対応します」ではなく「当社が対応します」「担当の田中が確認します」
- **一文に一つの内容**:長い文は2〜3文に分ける
- **あいまいな言い方を具体的にする**:「なるべく早く」→「11月20日までに」、「検討します」→「来週中に可否をお知らせします」
- **日付は月日まで書く**:「15日」ではなく「11月15日」。曜日も添えるとより確実です

遠回しな日本語は、遠回しな英語になります。断るなら断る、お願いするならお願いする、と日本語の段階ではっきりさせておくのがコツです。

### ステップ2:目的・相手・関係を指示に入れる

「英語にして」だけだと、無難で平均的な英文になりがちです。メールの目的と相手を伝えると、言い回しを場面に合わせやすくなります。

たとえば、次のように頼みます。

```
次の日本語のメールを英語のビジネスメールにしてください。
・相手:海外の取引先の購買担当者。何度かやり取りした間柄
・目的:出荷が遅れることを伝え、新しい出荷日を知らせる
・トーン:丁寧だが簡潔に。言い訳がましくしない
・条件:原文にない情報や約束は足さない。数字・日付・製品名・注文番号は原文のとおりに残す
・用語は次の英語に統一する:製品A=Product A、検収=acceptance inspection(社内で決めた表記があればそれに合わせる)

(ここに日本語の原文)
```

最後の「条件」が大切です。AIは親切に補足しようとすることがあるので、「足さない」「そのまま残す」と最初に書いておきます。社名や製品名の英語表記が決まっている場合は、その対応表も一緒に渡しましょう。

### ステップ3:数字・日付・否定・固有名詞を原文と突き合わせる

英文ができたら、まず次の4種類だけを、原文と1つずつ照らし合わせます。英語力がなくても確認できる部分です。

- **数字**:金額、数量、注文番号、単位(個・箱・ケースなど)
- **日付と時刻**:月日が合っているか。時刻があるならタイムゾーンも書いてあるか
- **打ち消し**:原文の「〜しない」「〜できない」「〜を除く」が、英文でも打ち消しになっているか
- **固有名詞**:会社名、人名、製品名、型番のつづり

日付は、国によって「月/日」と「日/月」の書き方が違うため、「11/12」のような数字だけの表記は読み違いのもとになります。「November 12」のように月を英単語で書くよう指示しておくと安心です。

照らし合わせは、原文と英文を左右や上下に並べて、蛍光ペンで印をつけるつもりで1か所ずつ見ていきます。AIに「数字・日付・固有名詞を原文と英文から抜き出して並べて」と頼み、その一覧を自分で確かめる方法もあります。ただし、最後は必ず自分の目で原文と見比べてください。

### ステップ4:逆翻訳で意味のずれを確かめる

英文の意味を日本語で確かめる方法が「逆翻訳」です。できた英文を、もう一度日本語に戻してもらいます。

ポイントは、**英文を作ったのとは別の会話(新しいチャット)で頼む**ことです。同じ会話の中だと、AIが元の日本語を覚えていて、それに合わせた訳を返してしまうことがあるためです。

```
次の英文メールを、意訳せずに直訳に近い日本語にしてください。
英文に書かれていないことは補わないでください。

(ここに英文)
```

戻ってきた日本語を、元の原文と比べます。見るのは次の点です。

- 原文にあった内容が、すべて残っているか(訳抜けがないか)
- 原文にない約束や条件が増えていないか
- 「お願い」が「命令」に、「できない」が「しにくい」に変わっていないか

ずれがあったら、その文だけを指定して「この部分は『〇〇』という意味にしたい」と直してもらいます。全文を作り直すより、ずれた箇所だけ直すほうが、ほかの部分が変わらずに済みます。

なお、逆翻訳で主に分かるのは「訳抜け」と「付け足し」です。AIは日本語に戻すときに、英文の不自然さや語感のずれをきれいな日本語に整えてしまうことがあるため、逆翻訳で問題がなくても、言い方まで適切とは限りません。言い方は次のステップ5で確かめます。

### ステップ5:丁寧さと態度を確かめる

内容が正しくても、言い方で相手の受け取り方は変わります。特に、謝罪、催促、お断りのメールは注意が必要です。

英語の細かい語感は自分では判断しにくいので、AIに「相手の立場でどう感じるか」を聞いてみます。

```
次の英文メールを、受け取った取引先の担当者の立場で読んでください。
1. 全体の印象(丁寧すぎる/ちょうどよい/冷たい・強い)
2. 強く聞こえる、または失礼に聞こえるおそれのある表現と、その理由
3. 意図(〇〇をお願いしたい)が伝わるか
を日本語で答えてください。

(ここに英文)
```

指摘を見て、直すかどうかは自分で決めます。AIの評価も絶対ではないので、気になる表現が残る場合は、英語が分かる同僚に一度見てもらうのが確実です。

### ステップ6:送る前の最終チェック

最後に、メールとして送る前の確認をします。英語に限らず、AIが関わったメールで抜けやすい部分です。

- 件名が本文の内容と合っているか(件名だけ日本語のまま、などになっていないか)
- 宛名と署名が正しいか
- 添付ファイルに触れているなら、実際に添付したか
- 返信が必要なら、何をいつまでに返してほしいかが書いてあるか
- AIへの指示文や、日本語のメモが本文に残っていないか

## 入力する前に気をつけること

英文メールには、取引先の名前や金額、社内の事情など、外に出したくない情報が含まれがちです。AIに貼り付ける前に、次の点を確かめておきましょう。

- **会社のルールを確認する**:業務で使ってよいAIサービスや、入力してよい情報の範囲が決まっていないか
- **入力データの扱いを確認する**:使っているサービスで、入力内容が学習や品質改善に使われる設定になっていないか。多くのサービスでは設定画面のプライバシーやデータに関する項目、または利用規約で確認できます。どこを見ればよいか分からない場合は、自己判断で使わず、社内の情報システム担当者に聞くのが確実です
- **伏せられる情報は伏せる**:相手の個人名やメールアドレス、口座情報などは「取引先A」「担当者B」のように置き換えてから入力し、英文ができたあとで自分で戻す

置き換えた場合は、戻すときに入れ間違えがないかもステップ3で一緒に確認します。

## AIの英文をそのまま使ってよい場面・人の確認が必須の場面

すべてのメールに同じ手間をかける必要はありません。間違えたときの影響の大きさで、確認の深さを変えます。

- **AIの英文+ステップ3と6の確認で十分なことが多い**:資料送付のお知らせ、受け取りのお礼など、内容が単純で誤解されても影響が小さいもの。ただし日程調整は、日付・時刻・タイムゾーンの読み違いが欠席につながるため、ステップ3だけは必ず行います
- **6ステップをすべて行う**:納期・価格・数量の連絡、お詫び、催促、お断りなど、相手の判断やお金に関わるもの
- **AIは下書きまで。必ず専門家や担当部署が確認する**:契約条件の合意、法的な通知、クレームへの正式回答、品質や安全に関わる説明など、誤りが許されないもの

契約や法的な文書は、言葉一つで意味が大きく変わります。AIの英文は「たたき台」と考え、社内の担当部署や専門家の確認を通すようにしてください。

## 具体例:出荷の遅れを伝えるメール

最後に、ここまでの手順を短い例で確かめてみます。

最初の日本語の下書きが、次のようなものだったとします。

> 先日の件ですが、来週中は難しいかもしれません。15日までには何とかします。

このまま訳すと、「何が」「いつから」遅れるのかがはっきりせず、「難しいかもしれない」「何とかする」というあいまいさも英文に残ります。

ここで、下書きに書かれていなかった情報(製品名・注文番号・当初の予定日・遅れの原因・相手にしてほしいこと)を、自分で確認して書き足します。AIに推測で補わせるのではなく、**人が事実を調べて日本語に書き込む**のがポイントです。ステップ1で整えると、次のようになります。

> ご注文いただいた製品A(注文番号1234)は、当初予定の11月10日に出荷できなくなりました。新しい出荷予定日は11月15日です。原因は部品の入荷の遅れです。11月15日の出荷で差し支えがある場合は、11月6日までにご連絡ください。ご迷惑をおかけし、申し訳ありません。

これをステップ2の指示で英語にすると、たとえば次のような英文になります。

> We regret to inform you that we will not be able to ship Product A (Order No. 1234) on November 10 as originally planned. The new shipping date is November 15. The delay is due to a late delivery of parts. If the new date causes any problems for you, please let us know by November 6. We apologize for the inconvenience.

ステップ3では、「Product A」「1234」「November 10」「November 15」「November 6」が原文と合っているか、「出荷できなくなりました」が「will not be able to ship」と打ち消しになっているかを確かめます。ステップ4の逆翻訳で、原文にない約束(たとえば「次回は割引します」のような一文)が足されていないかも見ます。

日本語の段階で具体的にしておけば、英文も具体的になり、確認もしやすくなります。

## まとめ:明日からの手順

英文メールを生成AIで作るときは、次の順番で進めてみてください。

1. 日本語の原文に主語・具体的な日付・はっきりした結論を書く
2. 相手・目的・トーンと「足さない・そのまま残す」を指示に入れる
3. 数字・日付・打ち消し・固有名詞を原文と1つずつ照らし合わせる
4. 新しいチャットで逆翻訳し、訳抜けと付け足しを探す
5. 相手の立場での印象をAIに聞き、強すぎる表現を直す
6. 件名・宛名・添付・AIへの指示文の消し忘れを確かめて送る

最初は時間がかかりますが、よく送るメールの指示文を保存しておけば、2回目からはぐっと楽になります。英語に自信がなくても、「日本語で確かめられる部分」を確実に押さえれば、送信ボタンを押すときの不安はかなり減らせるはずです。
