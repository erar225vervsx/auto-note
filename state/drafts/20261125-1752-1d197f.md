# 生成AIで日報・週報を作る 盛らずに伝わる5つの手順

日報や週報を生成AIに書かせてみたら、整った文章にはなった。でも読み返すと「顧客から高い評価を得た」「着実に前進した」など、自分が言っていない言葉が混ざっている。そんな経験はないでしょうか。

報告書は、上司やチームが判断に使う記録です。文章がきれいでも、事実が少しでも盛られていれば役に立ちません。逆に、事実さえ押さえていれば、生成AIは「まとめる・並べ直す・言い回しを整える」部分で頼れる道具になります。

この記事では、生成AIで日報・週報を作るときに、**盛らずに、読む人に伝わる形**に仕上げる手順を5つに分けて説明します。コピーしてそのまま使える頼み方の型と、提出前に見る5つの場所も載せます。

## 日報をAIに書かせると起きやすい3つのこと

最初に、何に気をつければよいかを整理しておきます。

- **書いていない成果が足される**:「対応した」が「迅速に対応し、信頼を得た」になるなど、AIは文章を自然にしようとして評価や効果を補いがちです。
- **うまくいかなかったことがぼかされる**:「先方の返事待ちで止まっている」が「調整を進めている」になると、上司は助けが必要だと気づけません。
- **数字や日付がずれる**:メモの「3件」が要約の途中で別の数字になったり、「来週」が具体的な日付に置き換わったりすることがあります。

生成AIの出力には誤りが混じることがあるため、人が目で確かめることが前提です。ASCII.jp の日報・週報の作り方を紹介する記事や、マネーフォワード クラウドのレポート作成の解説記事でも、AIの出力をそのまま使わず、人が確認することが勧められています(出典は記事末尾にまとめています)。

つまり、AIに任せるのは「文章の形」まで。「何があったか」は人が持っておく、というのが基本の考え方です。

## 手順1 業務中に「事実だけのメモ」を残す

日報の質は、AIに渡す材料で決まります。終業前に記憶をたどって書くより、仕事の区切りごとに短いメモを残すほうが、抜けも誤りも減ります。

メモは文章にしなくてかまいません。次の4つが分かれば十分です。

- **何をしたか**:作業名・案件名(社外の固有名詞は後で伏せます)
- **どこまで進んだか**:完了/途中/止まっている
- **数字**:件数・時間・金額など、あれば正確に
- **次にやること**:誰が・いつまでに

たとえば、こんなメモです。

```
・A社見積もり修正 完了 送付済み
・新人向け手順書 3章まで 4章は明日
・問い合わせ対応 5件 うち1件は回答待ち(担当部署に確認中)
・B社案件 先方の返事待ちで止まっている 金曜に再度連絡
```

ポイントは、**感想や評価を書かないこと**です。「順調」「いい感じ」と書くと、AIはそれをふくらませて文章にします。事実だけを渡せば、事実だけの報告になりやすくなります。

## 手順2 貼る前に、社外秘と個人名を伏せる

メモをAIに貼る前に、外に出してはいけない情報がないかを見ます。

- 顧客名・取引先名 → 「A社」「B社」に置き換える
- 個人名 → 「担当者」「先方の課長」などに置き換える
- 未発表の情報や詳しい売上の数字 → 書かない、またはぼかす

日報は社内向けの文書なので、つい気がゆるみがちです。けれど、AIに入力した時点で、その情報は社外のサービスに渡っています。会社の生成AI利用ルールがあれば、まずそれに従ってください。法人向けプランなど、入力内容を学習に使わない環境が用意されている場合は、そちらを使うのが安心です。法人プランがない場合は、使っているサービスに「入力内容を学習に使わせない」設定(オプトアウト)があるかを確かめてください。それも難しいときは、伏せ字を徹底します。マネーフォワード クラウドの解説記事でも、機密情報や個人名を伏せることや、オプトアウト設定・企業版の利用を検討することが挙げられています。

置き換えた名前は、最後に人が元に戻せば問題ありません。

## 手順3 「型」と「やってはいけないこと」を決めて頼む

AIへの頼み方は毎回考えるより、型を一度決めて使い回すほうが、出力が安定します。日報なら次のような型が使いやすいです。

```
あなたは社内向け日報の清書を手伝うアシスタントです。
下の【メモ】だけを材料に、日報を作ってください。

【形式】
■本日の実績(箇条書き)
■課題・相談したいこと(なければ「なし」)
■明日の予定(箇条書き)
全体で300字程度、です・ます調。

【守ること】
・メモに書かれていない成果、評価、感想を足さない
・数字、日付、件数はメモのとおりに書く
・メモから分からないことは、推測で埋めず「要確認」と書く
・止まっている作業、うまくいかなかったことは、ぼかさずにそのまま書く
・同じ案件の内容はまとめる

【メモ】
(ここに手順1のメモを貼る)
```

大事なのは【守ること】の最初の4行(足さない・数字はメモどおり・推測で埋めない・ぼかさない)です。このように明確に書くと、盛られた表現は出にくくなります。それでも出ることはあるので、次の手順で確かめます。

「課題・相談したいこと」の欄をわざと作っているのにも理由があります。筆者の考えでは、日報を読む上司にとって大切なのは「止まっていること」と「手助けが必要なこと」です。この欄があると、AIが問題を本文の中に埋もれさせにくくなります。

## 手順4 出力をメモと1行ずつ照らし合わせる

AIの出力を受け取ったら、提出する前に、メモと並べて確かめます。見るところは次の5つです。

- **足された言葉はないか**:「円滑に」「着実に」「高評価」「大幅に」など、メモにない評価の言葉。見つけたら消します。
- **数字は合っているか**:件数・時間・日付をメモと1つずつ照合します。
- **止まっている件が残っているか**:「返事待ち」「確認中」がやわらかい表現に変わっていないか。
- **主語は正しいか**:自分がやったことと、他の人がやったことが混ざっていないか。
- **「要確認」の箇所**:AIが分からないと書いた部分は、自分で埋めるか、本当に未確認なら「確認中」と書きます。

たとえば、手順1のメモから次のような出力が出たとします。

```
■本日の実績
・A社向け見積もりを迅速に修正し、送付しました。
・新人向け手順書を3章まで作成し、順調に進んでいます。
・問い合わせ5件に対応し、すべて解決しました。
```

照らし合わせると、直すべき点が4つ見つかります。

- 「迅速に」はメモにない評価です。
- 「順調に」もメモにない評価です。
- 「すべて解決しました」は誤りです。メモでは1件が回答待ちでした。
- B社案件が止まっていることが抜けています。また、明日の予定の欄もありません。

直したあとの例は次のとおりです。

```
■本日の実績
・A社向け見積もりを修正し、送付しました。
・新人向け手順書を3章まで作成しました。
・問い合わせ5件に対応しました。うち1件は担当部署に確認中です。

■課題・相談したいこと
・B社案件は先方の返事待ちで止まっています。

■明日の予定
・新人向け手順書の4章を作成します。
・B社には金曜に再度連絡します。
```

日報1本分なら、慣れれば長くはかかりません。省くと、誤った報告が記録として残ってしまうので、ここだけは毎回行ってください。

## 手順5 週報は「日報を束ねて、読む人に合わせる」

週報は、1週間分の日報(またはメモ)をまとめてAIに渡すと作りやすくなります。ここでも、材料は手順4で確かめ済みの日報にしておくのがコツです。確かめていない文章を束ねると、誤りもそのまま引き継がれます。

週報用の頼み方の例です。

```
下の【今週の日報】だけを材料に、上司向けの週報を作ってください。

【形式】
■今週の要点(3行以内。判断や手助けが必要なことを先に)
■案件別の進み具合(案件ごとに1〜2行)
■来週の予定

【守ること】
・日報に書かれていない成果、評価を足さない
・同じ案件は1つにまとめる
・数字と日付は日報のとおりに書く
・未解決の件は「未解決」と明記する

【今週の日報】
(月〜金の日報を貼る)
```

日報と違うのは、**読む人に合わせて順番を変えること**です。上司向けなら「判断が必要なこと」が先、チーム共有なら「他の人に影響があること」が先、というように、冒頭の要点に何を置くかを指定します。

できた週報も、手順4と同じ5つの見どころで確かめます。とくに「今週の要点」は短くまとめる分、言い過ぎや抜けが起きやすいので、元の日報と見比べてください。

たとえば、その週の金曜までの日報(4章は木曜に完成と報告済み、B社は金曜に再連絡しても返事待ちのまま、とします)から、こんな要点が出たとします。

```
■今週の要点
・各案件とも順調に進み、問い合わせ対応も滞りなく完了しました。
```

日報では、B社案件が返事待ちで止まり、問い合わせも1件が確認中でした。「順調」「滞りなく完了」は、日報と合いません。直すと次のようになります。2行目の「進め方の相談をさせてください」は、AIに書かせず自分で書き足した一文です。

```
■今週の要点
・B社案件が先方の返事待ちで止まっています。進め方の相談をさせてください。
・問い合わせ1件が担当部署に確認中です。
・新人向け手順書は4章まで作成しました。
```

短い要点ほど、元の日報とのずれが目立たなくなります。1行ずつ、どの日報に書いてあったかを確かめてください。

## AIに任せないほうがよい部分

日報・週報の中にも、AIに書かせないほうがよい部分があります。迷ったときは次の基準で分けてみてください。

- **自分の判断や意見**:「この案件は優先度を上げるべき」など。理由も含めて、自分の言葉で書きます。AIに書かせると、もっともらしいけれど自分の考えとは違う文章になりがちです。
- **謝罪やトラブルの経緯**:何が起きたか、誰に影響したかは、事実を自分で書きます。言い回しを整えるだけならAIに頼んでもかまいません。
- **人の評価に関わること**:同僚や部下の働きぶりへの言及は、AIに文章を作らせず、自分で書きます。

AIの役目は、「事実を並べて、読みやすい形に整える」ことです。何を報告し、どう判断するかは、書く人が決めます。

## 明日から始めるなら

最初から全部そろえなくても大丈夫です。まずは次の2つだけ試してみてください。

1. 明日の仕事中、区切りごとに「何を・どこまで・数字・次」の1行メモを残す
2. 終業前に、手順3の型にメモを貼って日報を作り、手順4の5つの見どころで確かめる

1週間続けば、そのまま週報の材料がそろいます。報告にかかる時間を減らしながら、中身は正確なまま。生成AIは、そのための清書係として使うのがちょうどよい距離感です。
