# 休み前の引き継ぎメモを生成AIで作る 抜けを防ぐ5手順

年末年始や有給で数日休む前、「自分がいない間、あの案件は大丈夫だろうか」と気になっていませんか。

この記事では、生成AIに**「代わりを受け持つ人の立場で質問してもらう」**ことで、自分では気づかない抜けを見つけながら、休暇前の引き継ぎメモを作る手順を5つに分けて説明します。最後に、コピーして使える空欄のひな形もつけました。

休み中に電話が来て結局自分が対応する、休み明けに止まっていた仕事が山になっている。そんな事態を減らすためのメモです。

## この記事の対象

対象は、異動や退職のような大がかりな引き継ぎではなく、数日〜1週間ほどの不在です。

- **交代で休む職場**や、個人で有給・長めの休みを取るとき:代わりを受け持つ同僚に渡すメモを作ります
- **会社全体が休みになるとき**:受け持つ人がいないので、「休み明けの自分と上司」に宛てたメモを作ります。こちらの場合の注意は、記事の後半にまとめました

## なぜ休み前の引き継ぎメモは抜けるのか

よくある失敗を整理します。

- **自分には当たり前のことを書かない**:「この取引先は午前中しか電話がつながらない」のような、慣れた人ほど意識していない情報が抜ける
- **作業の手順はあっても、判断の基準がない**:「先方から値引きの相談が来たら、どこまで受けてよいか」が書かれていない
- **休み直前にあわてて書く**:最終日の夕方に書き始めて、見直す時間がない
- **口頭だけで済ませる**:「何かあったら〇〇さんに聞いて」で終わり、聞かれた人も詳しく知らない
- **書いたメモと実際の状況がずれている**:書いたあとに状況が変わったのに、メモを直していない

人材管理サービスのカオナビの解説でも、引き継ぎがうまくいかない原因として、口頭だけで済ませること、業務が特定の人に頼りきりになっていること、引き継ぎの内容と実際の業務が違うことなどが挙げられています。

生成AIが役に立つのは、このうち「自分には当たり前で書かない」「判断の基準がない」の部分です。AIは業務の中身を知らないので、**知らない人の立場で質問してもらう**のに向いています。

## 手順1:不在中に動く仕事を書き出す(AIを使う前に)

最初の作業は、AIを使わずに自分でやります。カレンダー、メールの受信箱、タスク管理の画面を見ながら、**休みの期間中に「起きること」**を箇条書きにします。

- **期限が来るもの**:請求書の発行、定例の報告、契約の更新など
- **返事待ちのもの**:見積もりの回答待ち、確認依頼の返事待ちなど
- **来るかもしれない連絡**:問い合わせ、トラブル、急ぎの依頼など
- **毎日・毎週の決まった作業**:データの更新、在庫の確認など

ここでは文章にしなくてかまいません。「〇〇商事 見積 回答待ち 12/26ごろ」くらいのメモで十分です。このメモが**「元のメモ」**になります。

AIより先に自分で書き出すのは、**何が動いているかを知っているのは自分だけ**だからです。AIに「年末の引き継ぎ項目を挙げて」と頼んでも、一般的な項目しか出てきません。

## 手順2:AIに渡す「伏せ字版」を別に作る

元のメモはそのまま手元に残し、コピーしてAIに渡す用の**伏せ字版**を作ります。

- **取引先の会社名・担当者名**:「取引先A」「Aの担当者」のように置き換える
- **金額・数量**:「見積額(社内資料参照)」のように、本文から外す
- **日付**:期限の順番を整理するのに必要なので、残してかまいません
- **パスワード・IDなど**:元のメモにも、そもそも書かない

あわせて、「取引先A=〇〇商事」のような**対応表**を手元に作っておきます。元のメモと対応表は、AIには渡しません。

パスワードについては、タスク管理ツールの Asana の解説でも、引き継ぎ資料に直接書かず、パスワード管理ツールを使って受け渡すか、担当が変わるときにパスワードを変えるよう勧めています。引き継ぎメモは共有フォルダに置くこともあるので、AIを使うかどうかに関係なく守りたいルールです。

AIを使う前に、次の2点も確かめてください。

- **職場で使ってよいAIサービスか**:ChatGPT、Microsoft Copilot、Gemini など、どれを使ってよいかは職場によって違います。ルールがなければ、まず上司に確認します
- **入力した内容が学習に使われない設定か**:多くのサービスには、入力内容をAIの学習に使わせない設定があります。使う前に確認しておきます

伏せ字は大事な対策ですが、これだけで安全になるわけではありません。職場のルールと設定の確認を先に済ませましょう。

## 手順3:AIに「代わりを受け持つ人の立場」で質問してもらう

ここからAIを使います。メモをいきなり清書させるのではなく、**分からない点を質問してもらう**のがコツです。次のように頼みます。

```
あなたは、私が休みの間に仕事を代わりに受け持つ同僚です。
私の業務の中身はほとんど知りません。

下のメモを読んで、この内容だけでは対応に困る点を
質問の形で挙げてください。特に次の点を確認してください。
・いつまでに、何をすればよいかが分かるか
・相手から連絡が来たとき、どこまで自分で判断してよいか
・困ったときに、誰に聞けばよいか
・資料やデータがどこにあるか

質問は1つずつ番号をつけて、最大15個までにしてください。

【メモ】
(手順2で作った伏せ字版を貼る)
```

出てきた質問への答えは、**伏せ字版の各案件の下に「Q3の答え:〜」のように書き込みます**。同じ会話の中で「Q3:〜」と返事をして、そのまま手順4に進む方法でもかまいません。

答えを書くときも、**伏せ字は続けます**。ここで実名や金額を書いてしまうと、手順4でそのままAIに渡ってしまいます。

質問の中には、的外れなものや不要なものも混ざります。そうした質問は飛ばしてかまいません。

この手順で特に効くのが「どこまで自分で判断してよいか」です。たとえば次のように、**判断の線**を書き足せるようになります。

- 納期を延ばしてほしいと言われたら:年明け1週目までなら了承してよい。それ以上は休み明けに私から返事すると伝える
- 不具合の連絡が来たら:内容を聞き取って記録し、その日のうちに課長へ連絡する

## 手順4:答えを足したメモを、読みやすい形に整えてもらう

質問への答えを書き足したら、AIに形を整えてもらいます。

```
下のメモを、休み中に仕事を代わりに受け持つ人向けの
引き継ぎメモに整えてください。

・案件ごとに「状況」「やること・期限」「連絡が来たときの対応」「資料の場所」に分ける
・期限が早い順に並べる
・メモに書かれていないことは付け足さない
・分からない部分は推測せず「要確認」と書く

【メモ】
(質問に答えを書き足した伏せ字版)
```

大事なのは**「メモに書かれていないことは付け足さない」**という一文です。AIは、それらしい対応手順や期限を自分で補ってしまうことがあります。引き継ぎメモに事実でないことが混ざると、受け取った人はそれを信じて動きます。

整えてもらったあとは、手順2の対応表を見ながら、伏せた名前や金額を必要な分だけ自分で元に戻します。

### 仕上がりの例(1案件分)

たとえば、見積もりの回答待ちの案件なら、次のような形になります。名前や日付は架空の例です。

**〇〇商事 見積もりの回答待ち**

- **状況**:12月20日に見積書を送付済み。先方担当者から「年内に社内で検討する」と返事あり
- **やること・期限**:こちらからの連絡は不要。回答が来たら受け取るだけ
- **連絡が来たときの対応**:発注の連絡なら、お礼を伝えて「担当が休み明けの1月5日に正式にご連絡します」と返す。値引きの相談なら、その場では答えず、同じく休み明けに連絡すると伝える
- **資料の場所**:共有フォルダの「見積」→「〇〇商事」
- **困ったときに聞く人**:課長(同じ部署)
- **要確認**:先方の年末の最終営業日(休み前に確認する)

「連絡が来たときの対応」と「要確認」があれば、受け取った人が迷う場面を減らせます。

## 手順5:元のメモと見比べ、受け取る人と5分読み合わせる

最後に、2つの確認をします。

### 確認1:元のメモと見比べる

仕上がったメモを、手順1の**元のメモ**(伏せ字にする前のもの)と、手順3で書き足した答えと並べて、次の点を見ます。

- **期限や日付が変わっていないか**
- **書いていない対応や約束が増えていないか**
- **案件が1つ消えていないか**(数を数えると確実です)

AIの研修を手がける SHIFT AI の解説でも、AIの出力をそのまま使わず、業務を知る人が必ず確認することを勧めています。この場面で業務を一番知っているのは、書いた本人です。

### 確認2:受け取る人と読み合わせる

メモを渡して終わりにせず、受け取る人と5分だけ時間を取り、目の前で読んでもらいます。読みながら出た質問は、その場でメモに書き足します。

「ここはどういう意味?」と聞かれた箇所は、休み中に電話がかかってきやすい箇所です。読み合わせは、休み中の連絡を減らすための最後の仕上げだと考えてください。

## 会社全体が休みになるときは

代わりを受け持つ人がいない場合も、手順1〜5の流れは同じです。変えるのは次の4点です。

- **手順3の頼み方**:「休みの間に仕事を代わりに受け持つ同僚です」を「休み明けにこのメモだけを見て仕事を再開する、休み前のことを忘れた私です」に変える
- **手順4の宛先**:「休み中に仕事を代わりに受け持つ人向け」を「休み明けの自分と上司向け」に変える
- **手順5の読み合わせ**:上司に目を通してもらうか、書いた翌日に自分で読み直す
- **休み前にやること**:取引先への休業期間の案内と、本当に急ぐときの連絡方法(誰が、どこまで対応するか)を職場で決めておく

休み明けの初日に「何から手をつけるか」が書いてあるだけで、再開がずっと楽になります。

## 最終日にあわてないためのスケジュール

休み前の引き継ぎは、最終日に1回で終わらせようとすると抜けが出ます。たとえば次のように、数日に分けるのがおすすめです。

- **最終日の3〜4日前**:手順1の書き出しと手順2の伏せ字版づくり
- **2〜3日前**:手順3でAIに質問してもらい、答えを書き足す
- **前日**:手順4で整えて、手順5で見比べ・読み合わせ
- **最終日**:新しく増えた案件だけを書き足す

一度作った引き継ぎメモと、手順3・4で使った頼み方は保存しておきましょう。次の休みのときは、前回のメモを出発点にできます。

```
(案件の数だけ繰り返す)

```

## まとめ

- 不在中に動く仕事は、まず自分で「元のメモ」に書き出す
- AIには、名前と金額を伏せた「伏せ字版」だけを渡す。パスワードはどこにも書かない
- 使ってよいサービスか、学習に使われない設定かを先に確かめる
- AIには清書より先に「代わりを受け持つ人の立場での質問」を頼む
- 整えるときは「書かれていないことは付け足さない」と指示する
- 元のメモと見比べ、受け取る人と5分読み合わせる

引き継ぎメモは、相手のためだけでなく、休み中の自分を守るためのものでもあります。今年の休み前は、AIに「分からない点を聞いて」と頼むところから始めてみてください。
