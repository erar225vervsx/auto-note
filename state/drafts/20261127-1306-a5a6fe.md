# 生成AIで人事評価の自己評価を書く 盛らず埋もれない5手順

評価の時期が近づくと、自己評価シートの欄を前にして手が止まる、という方は多いのではないでしょうか。

「半年前に何をしていたか思い出せない」「書くと自慢か反省文のどちらかになる」「生成AIに頼んだら、立派すぎて自分の文章に見えない」。

この記事では、生成AIを「代わりに書いてもらう道具」ではなく、「材料を掘り出し、型に整え、言い過ぎを見つける相手」として使う5つの手順を紹介します。手順1と3は、自分では当たり前だと思っている貢献を拾い出して「埋もれさせない」ため、手順4と5は「盛らない」ための手順です。指示文は ChatGPT・Copilot・Gemini など、会社で使ってよいツールならどれでも使えます。コピーして使える指示文と、書き直しの例もつけています。

## まず、自己評価で何が見られているか

手順に入る前に、何を書けばよいかを確認しておきます。人事評価の解説記事では、おおむね次の点が共通して勧められています。

- **事実を客観的に書く**:主観だけで書くと、謙虚な人は反省文のように、自信のある人は言い訳のようになりがちです。
- **実績はできるだけ数字で示す**:達成率、件数、前年との比較などです。
- **行動と結果をつなげて書く**:「何をした結果、どうなったか」を示します。運や周りのおかげだけで説明しないことも大切です。
- **課題と次の行動を書く**:目標を達成していても、次の期にどう伸ばすかを書きます。

また、自己評価の項目は「成果(目標の達成度など)」「能力(企画力・実行力など)」「情意(責任感・協調性・報連相など)」の3つに分けて考えられることが多いようです。自分の会社のシートがどの分け方になっているかを、最初に見ておきましょう。

ここから分かるのは、自己評価で一番大事なのは「文章のうまさ」ではなく「材料の正確さ」だということです。生成AIは文章を整えるのは得意ですが、あなたが半年間に何をしたかは知りません。だからこそ、使い方の順番が大切になります。

## 手順1:材料は自分で集め、箇条書きのメモにする

最初の手順に、AIは使いません。期初に立てた目標と、それに対して実際にあったことを、手元の記録から拾い出します。

拾い出す先の例です。

- **期初の目標シート**:何を、どこまでやると書いたか
- **日報・週報・カレンダー**:月ごとに主な仕事を1〜2行
- **メールやチャット**:お礼を言われた、相談を受けた、トラブルを収めた場面
- **数字が出ている資料**:売上、件数、処理時間、問い合わせ数など

メモは文章にせず、短い箇条書きで十分です。

- 目標:問い合わせの一次回答を2営業日以内に
- 実際:4〜9月、2営業日以内の回答が多かったが、繁忙期の7月は遅れが出た
- やったこと:よくある質問の回答文を10件作り、チームで共有
- 困ったこと:7月は担当が1人休み、手が回らなかった
- 次にやりたいこと:回答文を増やし、1人休んでも一次回答できるようにする

「次にやりたいこと」は、AIに考えてもらうのではなく自分で決めて書きます。あとの手順で「メモにないことは足さない」と指示するためです。

もう一つのポイントは、**数字は元の資料で確かめたものだけを書く**ことです。記憶があいまいな数字は「多かった」「増えた」のままにしておき、あとで確かめます。

## 手順2:AIに渡す前に、名前や数字の一部を伏せる

自己評価の材料には、顧客名、同僚の名前、社内の数字などが含まれます。生成AIに貼る前に、次の点を確認してください。

- **会社のルール**:業務で生成AIを使ってよいか、使ってよいツールはどれか。決まったルールがなければ、上司や情報システムの担当者に一言確認する
- **ツールの設定**:入力した内容が学習に使われる設定になっていないか。使っているツールのヘルプや設定画面で、データの扱いについての項目を確認する
- **伏せる情報**:氏名、社員番号、給与・賞与、顧客名などは入れない。顧客名は「顧客A」のように置き換える

人事評価にAIを使う際の解説でも、個人情報を入力前に削除・匿名化すること、個人向けアカウントをそのまま業務に使わずデータの扱いを確認することが勧められています。

伏せたメモと、元のメモは別々に保存しておきます。最後に元のメモと見比べるためです。

## 手順3:AIに「質問役」をしてもらい、行動と結果のつながりを掘る

材料メモができたら、いきなり文章を書かせるのではなく、まず質問をしてもらいます。自分では当たり前すぎて書いていない工夫や、結果につながった理由が出てきやすくなるからです。

指示文の例です。

```
あなたは、私の上司として自己評価を読む立場です。
下の材料メモを読み、評価の根拠として足りない点について、私に質問してください。
条件:
・質問は5つまで。短い質問を箇条書きでまとめて出す
・「何をした結果、どうなったか」「数字で示せるか」「うまくいかなかった点は何か」を中心に
・人に頼られた、教えた、トラブルを防いだ、のような目立たない貢献がなかったかも聞く
・私の代わりに答えを考えたり、事実を推測したりしないでください

(ここに伏せ字にした材料メモを貼る)
```

返ってきた質問には、AIに返信するのではなく、手元のメモに書き足す形で答えます。たとえば「回答文を共有したことで、何か変わりましたか」と聞かれたら、「新しく入った人が、先輩に聞かずに一次回答できる場面が増えた」のように、分かる範囲で具体的に書きます。答えられない質問は、無理に埋めずに飛ばして構いません。

## 手順4:型を指定して下書きを作る

材料がそろったら、下書きを頼みます。このとき、文章の型と「書かないこと」をはっきり伝えます。生成AIは、入力していない事実を補って文章を整えてしまう場合があるためです。

```
下の材料メモだけを使って、人事評価の自己評価の下書きを作ってください。
型:目標 → 結果 → 結果につながった行動 → 課題 → 次の期にやること
条件:
・メモに書かれていない数字・出来事・成果は足さない
・数字はメモのとおりに書く。メモで「多かった」となっている所は数字にしない
・過度な自画自賛も、過度な謙遜もしない
・「頑張った」「努力した」のような言葉ではなく、行ったことを書く
・(会社のシートの文字数)字以内
・最後に、メモにない情報が必要だと思った箇所を「確認が必要な点」として箇条書きで出す

(ここに伏せ字にした材料メモと、手順3で書き足した答えを貼る)
```

項目が「成果」「能力」「情意」などに分かれているシートなら、項目ごとに分けて頼むと、話が混ざりにくくなります。

### 数字にしにくい仕事のとき

事務や管理部門など、成果を数字で示しにくい仕事もあります。その場合は、「どの状態になれば達成か」という基準を先に書き、その基準に対して何をしたかを振り返る、という書き方が人事評価の解説記事で勧められています。

たとえば「月末の書類の差し戻しを減らす」という目標なら、「差し戻しの理由を毎月まとめ、記入例を作って配った」のように、行動と、その後の変化を書きます。変化を数字で確かめられないなら、何で確かめたかが分かる言い方(「10月以降、同じ理由での差し戻しの連絡は経理から来ていない」など)にとどめ、言い過ぎないようにします。

### 目標に届かなかったとき

未達の項目は、つい言い訳か反省だけになりがちです。原因を自分の行動の側から見て、次に何をするかを具体的に書くと、面談で話し合いやすくなります。他のチームや環境のせいだけにしない、「次は頑張る」のような抽象的な決意で終わらせない、という2点を指示文に加えておくとよいでしょう。手順4の指示文の「条件」に、次の2行を足すだけで構いません。

```
・未達の理由は、自分の行動で変えられた点を中心に書く
・次の行動は、いつまでに何をするかが分かる形にする
```

## 手順5:元のメモと見比べ、盛り・ぼかしを点検する

下書きができたら、最後は自分の目で点検します。AIに「読みやすく」してもらった文章ほど、事実より少し大きく見える表現が入りやすいからです。

点検する項目です。

- **数字**:下書きの数字が、すべて元の資料と一致しているか
- **言い換え**:「改善した」が「大幅に改善した」、「担当した」が「主導した」になっていないか
- **足された話**:自分がしていない工夫や、聞いていない周りの評価が入っていないか
- **他責・言い訳**:うまくいかなかった理由が、他人や環境だけになっていないか
- **次の行動**:「意識する」「頑張る」で終わらず、具体的な行動になっているか
- **自分の言葉**:面談で聞かれたとき、自分の言葉で説明できる文になっているか

最後の項目は特に大切です。自己評価は、上司が読んで終わりではなく、面談で話す材料になります。普段使わない言い回しは、自分の言葉に直しておきましょう。

AIに点検を手伝ってもらうなら、次のように頼めます。

```
次の「自己評価の下書き」と「材料メモ」を見比べてください。
・下書きにあって、メモにない事実や数字
・メモより強い言い方になっている箇所(例:担当→主導)
を、該当する文を抜き出して一覧にしてください。直した文章は作らなくて結構です。
```

## 書き直しの例

手順を通すと、文章がどう変わるかの例です(架空の例です)。

**最初に自分で書いた文**

> 問い合わせ対応を頑張りました。忙しい時期もありましたが、できる限り早く回答するよう努力しました。今後も頑張ります。

**手順を通したあとの文**

> 目標は「問い合わせの一次回答を2営業日以内」でした。4〜9月の多くは目標内で回答できましたが、7月は担当者が1人休んだ期間に、回答が遅れた日がありました。
> 期中に、よくある質問への回答文を10件作ってチームで共有し、新しく入ったメンバーも先輩に確認せずに一次回答できる場面が増えました。
> 課題は、7月に1人休んだ際に一次回答が遅れたことです。次の期は、回答文の対象を増やし、1人休んでも一次回答できる状態を目指します。

「頑張りました」がなくなり、目標・結果・行動・課題・次の行動がそろいました。次の行動も、メモの「次にやりたいこと」から書いています。数字はメモで確かめた「2営業日」「10件」だけで、確かめていない割合などは入れていません。

## まとめ

生成AIで自己評価を書くときの5つの手順です。

- **手順1**:材料は自分で集め、確かめた数字だけをメモにする
- **手順2**:会社のルールと設定を確認し、名前や顧客名を伏せてから渡す
- **手順3**:AIに上司役として質問してもらい、行動と結果のつながりを掘る
- **手順4**:型と「メモにないことは足さない」を指定して下書きを作る
- **手順5**:元のメモと見比べ、盛り・ぼかし・他責を点検し、自分の言葉に直す

自己評価は、半年間の仕事を上司と話すための材料です。AIに任せるのは「整える」ところまでにして、中身は自分の記録から作りましょう。提出日の1週間ほど前に手順1を始めておくと、数字を確かめる時間も取れます。まずは今日、期初の目標シートを開いて、月ごとの仕事を1行ずつ書き出すところから始めてみてください。
