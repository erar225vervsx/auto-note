# 生成AIで発表の想定質問を準備する 答えに詰まらない5手順

社内の報告会や取引先への提案で、説明はうまくいったのに、最後の質疑で言葉に詰まってしまった。そんな経験はないでしょうか。

想定質問を準備しようとしても、自分で考えると「自分が説明したいこと」の裏返しの質問ばかりになりがちです。本当に聞かれるのは、相手が気にしている点です。

この記事では、生成AIに「聞き手の立場で質問してもらう」ことで、想定質問を広く集め、答えを自分の言葉で用意する5つの手順を紹介します。コピーして使える指示文と、想定問答メモの例もつけています。指示文は ChatGPT・Copilot・Gemini など、会社で使ってよいツールならどれでも使えます(入力内容の扱いは手順2で確認します)。

## 想定質問の準備でつまずきやすい3つの点

手順に入る前に、よくあるつまずきを整理しておきます。

- **自分の視点からしか質問を考えられない**:説明する側は内容を知りすぎているので、初めて聞く人がどこで引っかかるかに気づきにくくなります。
- **答えを文章で丸暗記してしまう**:原稿どおりの質問が来ないと、とたんに崩れます。
- **答えの根拠があいまい**:「たぶんこのくらい」という数字で答えると、追加で聞かれたときに困ります。

生成AIは、1つめの「視点を増やす」ところで特に役に立ちます。2つめと3つめは、使い方を間違えるとかえって悪くなるところなので、手順の中で注意点を押さえます。

## 手順1:聞き手を具体的に書き出す

最初に、誰が聞くのかを書き出します。AIに質問を出してもらうとき、聞き手の姿が具体的なほど、質問も具体的になりやすいからです。

書き出す項目の例です。

- **立場**:決める人(部長・取引先の担当役員など)、実際に使う人、関係部署の人
- **気にしていそうなこと**:費用、手間、今のやり方を変える負担、失敗したときの影響
- **前提として知っていること・知らないこと**:専門用語が通じるか、これまでの経緯を知っているか
- **時間**:質疑に何分くらい取れるか

聞き手がはっきりしない場合は、「この内容に関心を持ちそうな聞き手を3通り挙げてください」とAIに聞くところから始めても構いません。ただし、最後は自分の知っている実際の聞き手に合わせて選び直します。

## 手順2:資料の要点を、伏せるところを伏せてから渡す

次に、発表の要点をAIに渡します。資料をそのまま貼るのではなく、要点を箇条書きにして渡します。伏せる情報を選びやすく、発表で一番伝えたいことに沿った質問が出やすくなるからです。資料には載せているが要点から省いたことがあれば、「資料には◯◯も載せている」と一言添えておきます。

渡す前に確認することです。

- **会社のルール**:業務で生成AIを使ってよいか、使ってよいツールはどれか。決まりがなければ、上司や情報システムの担当者に確認する
- **ツールの種類**:無料の個人アカウントに社内の情報を入れない。入力内容が学習に使われない設定やプランかを確認する。分からなければ情報システムの担当者に聞く
- **伏せる情報**:顧客名、個人名、まだ公表していない数字などは伏せる。顧客名は「顧客A」のように置き換える
- **数字の扱い**:数字は元のデータで確かめたものだけを書く

お名前.com ビジネスコンシェルジュの解説でも、入力してよい情報の範囲が決まっていない場合は固有名詞を伏せて要点だけを渡すか、入力データを学習に使わない設定ができる法人向けプランを使うこと、数字は人が出典のある元データを用意することが勧められています。

## 手順3:立場ごとに質問を出してもらう

ここが中心の手順です。聞き手の立場ごとに、質問を出してもらいます。

```
あなたは、下の発表を聞く「(手順1で書いた聞き手。例:費用に厳しい部長)」です。
発表の要点を読み、質疑で聞きたくなる質問を挙げてください。
条件:
・質問は5つまで。短く、箇条書きで
・賛成していない人が聞きそうな、厳しい質問も入れる
・下の要点に書かれていないが、聞き手が気にしそうな点を優先する
・「資料に載せている」と書いた点は、資料で説明済みとして扱う
・答えは書かない

(ここに伏せ字にした発表の要点と、「資料には◯◯も載せている」の一言を貼る)
```

「答えは書かない」と入れているのは、AIの答えをそのまま覚えてしまうのを防ぐためです。答えは手順4で自分で作ります。

聞き手が複数いる場合は、立場を変えて同じ指示を繰り返します。決める人、実際に使う人、反対しそうな人の3通りくらいで試すと、質問の幅が出やすくなります。

### 集まった質問を絞る

出てきた質問を全部準備する必要はありません。次の3つに分けます。

- **必ず準備する**:聞かれる可能性が高く、答えに詰まると話が止まるもの(費用、期間、効果の根拠など)
- **軽く準備する**:聞かれるかもしれないが、一言で答えられるもの
- **準備しない**:発表の目的から外れているもの

質疑の時間が短いほど、「必ず準備する」は絞り込みます。手順1で書いた時間を目安にしてください。「必ず準備する」が多すぎるときは、発表本体に答えを入れてしまうのも一つの方法です。何度も聞かれそうなことは、質疑を待たずに説明しておけば済みます。

## 手順4:答えの骨組みは自分で作り、AIで短く整える

答えは、文章ではなく骨組みで用意します。

- **結論**:一言で
- **理由**:1〜2点
- **根拠**:数字・事実・資料のページ
- **分からないとき**:「確認して、◯日までにお返しします」

骨組みを自分で書いたら、AIには短く言いやすく整えるところだけを頼みます。

```
下は、発表の質疑で聞かれそうな質問と、私が用意した答えの骨組みです。
口頭で30秒以内に言える長さに整えてください。
条件:
・結論から言う形にする
・骨組みにない数字・事実・約束は足さない
・数字や固有名詞で確かめが必要なものは[要確認]と書く
・「分からないとき」の行は、期限も含めて一字も変えない

(ここに質問と答えの骨組みを貼る)
```

AIは文章を整えるとき、もっともらしい数字や事実を補ってしまうことがあります。整えたあとの答えに、骨組みになかった数字や「必ず」「すぐに」のような約束が入っていないかを、必ず見比べてください。

### 答えられない質問を、準備の段階で決めておく

全部の質問に、その場で答えられる必要はありません。むしろ、確かめていないことをその場で言い切るほうが、あとで困ります。

「この質問は、今は数字を持っていないので確認して返す」と、準備の段階で決めておきましょう。そうすると、本番で聞かれても落ち着いて返せます。

## 手順5:AIに質問役をしてもらい、声に出して練習する

最後に、答えを声に出して練習します。ここでもAIに質問役を頼めます。

```
あなたは、下の発表を聞いた「(聞き手)」です。
これから質疑の練習をします。質問は1回に1つだけにし、私の返事を待ってから次へ進んでください。
私が答えたら、その答えで足りない点を1つだけ指摘し、続けて次の質問を1つしてください。
これを5回繰り返します。

(ここに伏せ字にした発表の要点を貼る)
```

練習のときは、用意した答えを読み上げるのではなく、骨組みを見ながら自分の言葉で答えます。質問が来たら、まず声に出して答えながら、スマホのタイマーで30秒を計ります。言い終えたら、答えの要点だけを打ち込んでAIに送り、次の指摘と質問を受け取ります。使っているアプリに音声入力があれば、話した内容をそのまま送っても構いません。

指摘をすべて取り入れる必要はありません。実際の聞き手を知っているのはあなたです。「この人はそこまで聞かない」と思う指摘は、読み流して構いません。

## 想定問答メモの例

手順を通すと、手元に残るメモはこのような形になります(架空の例です)。

**質問**:今のやり方を変えると、現場の手間はどのくらい増えますか。

- **結論**:最初の1か月は増えますが、その後は今と同じか少なくなる見込みです
- **理由**:入力の項目を減らすので、慣れれば作業は短くなります
- **根拠**:試しに使った2人の記録(資料8ページ)
- **分からないとき**:部署全体での影響は、来月の試行後にお返しします

**追加の質問**:2人だけの記録で判断できますか。

- **結論**:2人分では足りないので、来月に部署全体で試します
- **理由**:人によって慣れ方が違うためです
- **分からないとき**:試行の結果は、来月末の定例でお伝えします

**質問**:費用はどこから出しますか。

- **結論**:今期の部の予算の範囲で始めます
- **理由**:最初は少人数で始めるので、費用は月◯万円で、部の予算の範囲に収まります
- **根拠**:経理と確認済み(資料10ページ)
- **分からないとき**:来期以降の費用は、予算の会議で決まり次第お伝えします

文章ではなく骨組みなので、質問の言い方が少し違っても、結論から答えられます。

## まとめ

生成AIで想定質問を準備する5つの手順です。

- **手順1**:聞き手の立場・気にしていること・知っていることを書き出す
- **手順2**:会社のルールを確認し、顧客名や未公表の数字を伏せて要点を渡す
- **手順3**:立場ごとに、答えなしで質問だけを出してもらい、準備するものを絞る
- **手順4**:答えの骨組みは自分で作り、AIには短く整えるところだけ頼む
- **手順5**:AIに質問役をしてもらい、骨組みを見ながら声に出して練習する

AIに任せるのは「質問を増やす」「言いやすく整える」「練習相手になる」ところまでです。答えの中身と根拠は、自分の資料から用意しましょう。発表の数日前に始めておくと、練習の時間も取れます。まずは次の発表の聞き手を1人思い浮かべて、その人が気にしていそうなことを3つ書き出すところから始めてみてください。
