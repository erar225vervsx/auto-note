# 生成AIでビジネスメール 場面別プロンプト10本と確認表

催促もお断りも日程調整も、【 】を埋めて貼るだけで下書きが出る。そんなメール用プロンプトの型と、送る前の確認表をまとめました。

「依頼のメール、また一から書いている」「催促したいけれど角が立たない書き方が分からない」。生成AIに頼んでみたものの、毎回プロンプトを考えるのが面倒で、結局自分で書いてしまう。そんな方に向けた記事です。

悩みはたいてい次の2つです。

- **頼み方が毎回ばらばら**:目的や相手が伝わらず、使えない下書きが返ってくる
- **確認のしかたが決まっていない**:敬語の誤りや、頼んでいない約束・日付を見落とす

この記事では、無料部分で「メール用プロンプトの共通の型」と「送る前の確認の流れ」を説明します。有料部分には、場面別にそのまま貼って使えるプロンプト10本と、場面ごとに見るべき点をまとめた確認表を置いています。

## なぜ「メールを書いて」だけではうまくいかないのか

生成AIは、情報が足りない部分を推測で埋めて「それらしい文面」を作ります。

たとえば「取引先に資料送付のメールを書いて」とだけ頼むと、次のようなことが起こりがちです。

- 相手との関係が分からず、丁寧すぎる、またはくだけすぎる文面になる
- 返事が必要かどうか分からず、「ご確認ください」で終わる
- 決めていない期限や、存在しない添付ファイルの説明が入る

WEEL、Yoom、ITmedia ビジネスオンラインなどのメール作成の解説記事が、そろって「誰に・何の目的で・何を伝えるか」を具体的に書くよう勧めているのは、このためです。

短い例で比べてみます。

- **悪い頼み方**:「取引先に資料送付のメールを書いて」
- **良い頼み方**:「何度かやりとりのあるA社のB様に、来月の打ち合わせ用の資料2点を送るメール。今週中に目を通してほしい。返信は不要。5行程度で」

後者なら、相手との距離感、資料の数、お願いの中身がAIに伝わります。

## メール用プロンプトの共通の型

場面が変わっても、AIに渡す情報はほぼ同じです。次の7項目を毎回埋めるようにすると、下書きの質が安定します。

- **相手**:社外か社内か、立場、関係の深さ
- **目的**:相手に何をしてほしいか(読む・返信・作業・判断)
- **伝える事実**:日付、金額、資料名、経緯など
- **お願いや期限**:いつまでに、何をしてほしいか
- **トーン**:丁寧に、簡潔に、やわらかく、など
- **長さ**:目安の行数
- **書かないこと**:まだ決まっていないこと、約束できないこと

これを型にすると、次のようになります。

```
あなたは日本の会社で働く、ビジネスメールに慣れた担当者です。
次の情報だけを使って、メールの下書きを作ってください。

【相手】
【このメールの目的】
【伝える事実】
【お願いと期限】
【トーン】
【長さの目安】
【書かないこと】

守ること:
1. 【伝える事実】にない日付・金額・約束・理由は書かない。必要なのに情報がない箇所は【要確認】と書く
2. 件名を1つ、本文を1つ出す
3. 敬語は、尊敬語と謙譲語を取り違えないようにする
4. 最後に、私が確認すべき点を箇条書きで3つ以内で挙げる
```

ポイントは「守ること」の1番です。AIが空白を推測で埋めにくくなり、【要確認】が出れば人が確かめる場所がひと目で分かります。

ただし、指示しても日付や金額を勝手に入れることはあります。【要確認】が出なかったから安全、とは考えず、後で説明する確認の流れで必ず見てください。

4番のように、AI自身に事実の抜けや迷いどころを挙げさせると、見落としが減ります。

## 情報を入れる前に:伏せるものを決める

この型はChatGPT、Copilot、Geminiなど、どの生成AIでも使えます。ただし、会社で使ってよいと決められたツールを使ってください。

メールの下書きには、相手の名前や会社名、金額、案件名が入りがちです。社内で入力してよい情報のルールがあれば、まずそれに従ってください。

ルールがはっきりしない場合は、次のように置き換えて入力すると安心です。

- 会社名・個人名 → 「A社」「B様」
- 案件名 → 「〇〇案件」
- 金額・契約条件 → 「金額X」

本当の名前や数字は、送る直前にメールソフト上で差し替えます。

## 送る前の確認の流れ

AIの下書きは「たたき台」です。送る前に、影響の大きい順に見てください。

1. **事実**:日付・曜日・金額・資料名・相手の名前が、自分のメモと一致しているか
2. **約束**:できない約束や、決めていない期限が入っていないか
3. **お願い**:相手に何をしてほしいかが、1回読んで分かるか
4. **敬語**:相手の行為に謙譲語を使っていないか(「ご拝読ください」など)
5. **長さ**:スマホで読んでも、要件が最初の数行で分かるか

【要確認】が残っていたら、そのまま送らないように気をつけてください。送信前に「要確認」で文面を検索する習慣をつけると安全です。

## 場面ごとに型を用意しておくと楽になる

共通の型だけでも十分使えますが、場面ごとに「入れるべき情報」と「気をつける点」は少しずつ違います。

- **催促**では、相手を責めない言い回しと、行き違いへの配慮
- **お断り**では、理由をどこまで書くかと、代わりの提案
- **日程調整**では、候補日の曜日の誤りと、所要時間・形式
- **返信遅れのお詫び**では、言い訳を長くしないこと

ここから先の有料部分では、よく使う10の場面について、この違いを最初から入れた「そのまま貼って使えるプロンプト」と確認ポイント、催促メールの入力から修正までの使用例をまとめています。

## 場面別プロンプト10本

どのプロンプトも、【 】の中を埋めて使います。埋められない項目は空欄のままで構いません。AIが【要確認】と書くことが多いので、送る前に埋めてください。

名前・連絡先・金額は、無料部分で説明したとおり「B様」「金額X」などの仮名で入れ、送る直前にメールソフト上で差し替えます。

収録している場面は次の10です。

1. 仕事の依頼
2. 返信がない相手への催促(使用例つき)
3. 日程調整
4. お断り
5. お礼
6. 資料・見積書の送付
7. 確認・質問
8. 返信が遅れたお詫び
9. 社内への連絡・共有
10. 担当交代・異動のあいさつ

各プロンプトには、場面に合ったトーンや長さをあらかじめ入れてあります。書いていない場面は、必要なら共通の型から【トーン】【長さの目安】を足してください。

各プロンプトの最後にある「↓ここに共通ルールを貼る」の行は、次の共通ルールに置き換えてから送ってください。毎回書くのが面倒なら、メモアプリや、PC・スマホの単語登録(辞書登録)に入れておくと便利です。

```
共通ルール:
1. 上に書いた情報にない日付・金額・約束・理由は書かない。必要なのに情報がない箇所は【要確認】と書く
2. 件名を1つ、本文を1つ出す
3. 尊敬語と謙譲語を取り違えない
4. 最後に、私が確認すべき点を3つ以内で挙げる
5. 【書かないこと】に書いた内容には触れない
```

## 下書きを直してもらうときの一言集

一度で思った文面にならないときは、全部を作り直させるより、直す点を一言で伝える方が早く仕上がります。

- **長いとき**:「要件を変えずに、本文を半分くらいの長さにしてください」
- **かたいとき**:「失礼にならない範囲で、もう少しやわらかい言い方にしてください」
- **要件が見えにくいとき**:「相手にしてほしいことを、本文の最初の段落に移してください」
- **敬語が気になるとき**:「この文面の敬語で、使い方が不自然な箇所があれば指摘してください」

## 送信前の確認表(全場面共通)

どの場面でも、送る前に次の項目を見てください。

- **【要確認】**:文面に「要確認」が残っていないか
- **宛先**:宛先・CC・BCCが正しいか。社外に社内向けの内容を送っていないか
- **名前**:相手の会社名・名前・肩書きの漢字が正しいか
- **日付**:日付と曜日の組み合わせが正しいか
- **数字**:金額・数量・時間が、元の資料と一致しているか
- **約束**:自分が決めていない約束や期限が入っていないか
- **添付**:書いた添付ファイルを、実際に添付したか
- **お願い**:相手にしてほしいことが、1回読んで分かるか
- **敬語**:相手の行為に謙譲語を使っていないか
- **件名**:件名だけで、何のメールか分かるか

## まとめ

型を決めて中身を埋め、「書いていないことは【要確認】」のルールを付け、送る前に確認表で事実と約束を確かめる。これが基本です。
